**记录来源**：研究者在 ChatGPT 研究规划对话中明确提出。

**CONFIRMED — 协作约定**
- 双方共同使用 GitHub 私人仓库 `cui-gx/phd-research`。每次有实质性研究讨论或开发实验任务，**开始前读取最新版，结束时更新重要结论与最新进展**。
- 研究规划侧负责整理科学问题、确认后的研究设计与实验解释；代码实验侧负责维护实施状态、测量和可复现信息；双方通过 GitHub 交接，不依赖 ChatGPT Library 的自动同步。
- GitHub `main` 是目前的共享权威来源；Library 副本不可覆盖 GitHub 新版本。冲突需合并，禁止强制推送覆盖他人修改。
- 提交使用研究者授权的 GitHub 账号和身份，提交说明不包含 AI 工具署名或 `Co-authored-by` 尾注。

**CONFIRMED — P1 关键背景（详见总档案）**
- 单 GPU：1× NVIDIA RTX PRO 6000 96GB（从原 2 GPU 计划修订）。
- FSD-EY（PDB 1FME）、OpenMM、CVAE、优先利用 DeepDriveMD/Colmena。
- 固定计算预算下 MD 与 AI 任务时序对构象空间探索的影响；科研目标是资源有效利用，而非开发蛋白质折叠方法。
- 历史数据驱动的预测重点：单次科学工作流内 AI 更新是否值得、能否改变后续候选选择、更新成本是否能在剩余时间内兑现。
