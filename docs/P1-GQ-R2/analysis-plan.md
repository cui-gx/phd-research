# GQ-R2 事前分析計画 v1

2026-10-26。状態：探索的方法開発。研究者が承認した対象・計算範囲は CONFIRMED、以下の数値的な操作定義は PROPOSED。計画の push と遠隔確認の後に解析する。将来の方策比較の勝敗を見て閾値を選ばない。

## 問いと対象

固定された MD 条件下で、既探索集合に追加された、物理的に区別可能な局所構造領域を再現可能に記述できるか。折り畳み、天然構造回復、準安定状態の発見、平衡分布の推定は対象外。

GQ-R1 の NoCutoff 4本×4 ns（各 8,000 フレーム、保存間隔0.5 ps）だけを使う。最初の1 nsと checkpoint 継続3 nsは同じ系列である。3本のcutoff短時間試行を除く。原入力・DCD・XML・既存特特徴量を SHA-256 で照合し、原子順序を確認する。R1の原資料を上書きしない。

## 品質適格性

全32,000フレームで原子数504、残基数28、Cα数28、座標・54主鎖角の有限性を検査する。実際のSystem XMLの拘束長誤差≤0.01 Å、隣接Cα距離2.5–5 Å、隣接ペプチドC–N距離0.8–2 Å、非隣接残基間の重原子最短距離≥0.8 Åを保守的な異常検出条件とする。N–Cα–C–Cβの符号を同一準備構造と比較する。これはL配置や力場の正しさの認証ではない。高エネルギーは各系列の中央値とMADの10倍超を警告するが、自動除外しない。温度、Rg、接触数、エネルギーの時間推移を併記する。既存の5 ps抽出検査を全フレーム検査と混同しない。

除外候補は0/100/200/500 ps。最後は追加感度分析であり、平衡化の証明ではない。異常フレームは代表としても支持フレームとしても使わず、理由と元frame IDを保存する。

## 距離と二つの評価器

28残基の |j−i|≥3 の325組について、D(x)=(|r_i−r_j|) とし、d(x,y)=sqrt(Σ_k(D_k(x)−D_k(y))²/325) [Å]。平行移動・回転に不変だが鏡像に不変でもあるため、手性検査を併用する。周期境界の最小像処理は行わない。補助診断は周期的phi/psi差、Cα Rg、8 Å非局所接触割合とする。

A：時間順の増分ε領域。最初の適格フレームを種代表とする。既存代表から全てεより遠いフレームを仮代表とし、続く適格フレームが仮代表のε内に連続して存在する時間がτ psに達した時点で登録する。間に既知領域へ戻る、別候補へ移る、または品質不適格なら支持をリセットする。仮代表は固定し、登録前に既存代表と再照合する。τ=0は単純な貪欲ε-net、τ>0は滞在の工学的条件であり準安定性ではない。重複時刻は支持時間を増やさない。最初の種領域と追加領域を分ける。領域は閉球の分割ではなく、代表間距離>εの順序依存被覆である。

B：校正系列11/12から、固定の時間順にτ=0の同一貪欲法で構築する参照代表庫。13/14への最近傍距離、訪問代表数、庫外率を報告する。庫外フレームを個別の新状態に数えない。校正と参照構築で同じデータを使うため校正系列内の良さは確認的証拠ではない。

## 閾値、時間、順序

ε候補=[0.5,1,1.5,2,3,4] Å。主解析は除外100 ps・間隔2 ps・τ=5 ps。完全なε×τ=[0,2,5,10] ps×除外[0,100,200,500] ps×間隔[0.5,1,2,5] ps×4系列の感度表を保存する（1,536条件）。この組合せ数を超えて結果都合で探索しない。

閾値根拠は11/12の短時間差0.5/1/2/5/10/20/50/100 psでの距離・角度差の分布、最初の100 psとの差、長時間/系列間の差。短時間差も真の熱雑音だけではない。量子化精度、熱変動、局所構造変化が分離しない場合は唯一のεを確定しない。13/14は既にR1で見ているため盲検ではなく、探索的な別系列検査である。追加の独立データなしに普遍性を認証しない。

順序効果はτ=0で順方向・逆方向・固定seed 20261026のシャッフルを同じframe ID集合に適用する。シャッフルに物理時間の持続条件を適用しない。比較参照として各系列の均等抽出最大512フレームで、最初の代表を固定frame IDとした最遠点法ε-coverを実装し、小規模の厳密距離と分割計算を照合する。32,000²の距離行列は作らない。

## 負対照と独立診断

同一構造の反復挿入、同一時刻複製、剛体変換、サンプリング間隔、隣接時刻、除外時間、人工Cαガウス摂動σ=[1e−6,0.01,0.05,0.1] Å、全原子鏡像、ペプチドNの10 Å移動を検査する。摂動は合成対照でありMDではない。時間順に緩慢に変わる構造も新領域を生じ得るため、領域数を科学的発見数と呼ばない。登録代表への構造変化を主鎖角、Rg、接触で併記し、距離だけによる過剰解釈を調べる。

## 将来のC/Bとの接続

共通履歴A0、時刻付き品質適格な将来集合F、ε/τ/標本化、データ公開時刻と資格判定時刻を別々に渡す。将来枝ごとに同じA0から開始し、既存A0と新代表の双方と重複排除する。共通履歴全点への距離を省略しない。等MD量と等wall-clockの終端を区別し、期限後の支持フレームを使わない。Xは決定前履歴、Yは将来MDであり、同じ記述子による機械的関連は別途開示する。本輪では予測器も分岐MDも実行しない。

## 計算・統計・停止

本人領域のCPUのみ、論理CPU最大3、数値スレッド2、RSS16 GiB・新規データ5 GiB以下。GPUを不可視化しOpenMM Contextを作らない。新隔離環境はCPU解析依存のみ。1解析プロセスの壁時計上限2,400秒、必要なら独立した品質・距離・評価段に分割し各出力を保存する。上限に達したら未完を報告し、無断で範囲を増やさない。距離をブロック化し、キャッシュと小標本誤差チェックを使う。全フレームは独立標本ではなく、4系列も同じ初期構造条件付きである。フレーム単位の信頼区間を作らない。

検査実装の成功と科学資格を区別する。閾値が解釈不能、松弛/時間/順序依存が著しい、角度診断が矛盾、品質異常を検出できない場合は REPEAT/NOT READY とする。探索的候補が計算できても独立確認がなければ CONDITIONAL PASS に留め得る。感度比は数値を全て示し、未承認の合格率を事後に創作しない。
