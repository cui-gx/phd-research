# B1申請前の資格判断

2026-10-26。研究者・計画側への判断材料であり、新規実行許可ではない。以下は実行端の自己評価であり、研究者による受入れや独立審査の完了ではない。

| 対象 | 本輪判断 | 根拠 |
|---|---|---|
| 工学的納品 | PASS | 二つの実装、9試験、全感度表、全点品質、失敗・SHA・日語報告 |
| 粗い物理異常検出 | CONDITIONAL PASS | 全点検査と人工異常の検出。科学的完全性は未認証 |
| 増分・固定庫評価の計算可能性 | PASS | 有界CPUで完了、厳密小標本との距離一致 |
| 唯一の物理解像度 | NOT READY | 時差分布が連続し、ε/τの非単調性が大きい |
| 独立確認 | NOT READY | 同じ準備構造の4系列、全て既知の探索データ |
| 正式B1成果指標 | NOT READY | 固定尺度と未知データの適用境界が未確定 |

総合的な科学資格は **NOT READY**。これは研究の価値がないという判断ではなく、このまま正式な更新効果を測ると成果定義の選択が結論を左右し得るという判断である。プログラムが動くことを科学PASSに読み替えない。

## 支持できる結論

現データに明白な粗い幾何異常は検出されなかった。固定された操作規則の下で局所構造領域数と庫外率を計算できる。2 Å付近には主鎖角変化に対応する代表差があり、単なる1構造の反復ではない。反面、尺度・持続・構庫の定義が結果を大きく変えることも確認した。

## 支持できない結論

正しい局所状態数、全構象空間被覆率、熱揺らぎと有益な探索の厳密分離、十分なburn-in、平衡性、準安定性、CVAE更新の利益、Cの予測増分、固定時間の科学純利益は示していない。

## 最小限不足しているもの（PROPOSED）

1. 初期構造準備・質子化・溶媒モデルの確認と、緩和を評価する独立条件。
2. 現32,000フレームから隔離された新しい校正/確認系列。準備条件を変えず新seedだけを増やしても準備依存は検証できない。少数の別準備条件×複数確率流が候補だが、必要長・本数・予算は未決であり統計的認証を付けない。
3. ε・τ・保存間隔・除外と品質規則の同時の事前凍結。可能なら連続距離・角度変化などを補助評価として併記し、単一の状態数だけで結論を作らない。
4. 共通履歴A₀、公開/資格確定時刻、等MD量と等壁時計の終端の完全な実験カード。

独立校正の前に本輪で最も見栄えのよいεを採用して正式B1を申請することは勧めない。研究者が適用範囲を限定した診断を選ぶ場合も別承認が必要。本輪では次段階の実行promptやGPUタスクを自動生成しない。S2補充独立終審INCOMPLETE、S3 NOT APPROVEDを維持する。
