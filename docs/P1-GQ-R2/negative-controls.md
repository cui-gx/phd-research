# 負対照、境界検査、失敗の解釈

合成操作を実MDとして扱わない。負対照は9件のプログラム試験と実データ上の感度解析を組み合わせた。PASSは各操作に対する実装挙動であり科学的閾値の認証ではない。

| 検査 | 結果 | 解釈 |
|---|---|---|
| 同一構造を100回 | 種1代表のみ | 単純な反復を新領域として加算しない |
| 同じ時刻で各点を2回反復 | 6尺度すべて代表数同一 | 重複で支持時間を増やさない |
| 剛体回転・平行移動 | d差1.745×10⁻¹⁵ Å | 数値容差内で不変 |
| Cα鏡像 | d=0 | 既知の欠点を検出した対照。鏡像を識別できたというPASSではない |
| 全原子鏡像 | 26手性反転、除外 | 相対手性検査の必要性を確認 |
| ペプチドNを人工10 Å移動 | ペプチド/拘束/手性で除外 | 明白な異常の検出。微妙な非物理構造の網羅性は未検証 |
| 人工Cα摂動σ≤0.1 Å | 各100点、ε0.5 Åで種1のみ | 微小な算術摂動は分裂しなかった。熱運動の認証ではない |
| 非適格点・時間欠落 | 支持をリセット | 隔離された点を連続滞在とみなさない |
| 共通履歴と公開期限 | 既往点を排除、期限後支持を不使用 | 将来の枝比較用の境界を検査 |
| 順序変更 | ε2 Å、系列11で34–43代表 | 順序不変ではない。固定順序の操作量に限定 |
| 保存頻度・隣接点 | 全感度表に保持 | 相関フレームを独立の発見と解釈しない |
| 緩和除外 | 500 psでも変化は残る | 初期松弛と科学探索を完全分離できていない |
| εとτ | 小εで支持失敗、大εで登録再増加 | 探索指標の科学資格に対する主要な負の結果 |

最初の校正失敗は空分布のIndexErrorで、原データではなく集計の端点処理の問題だった。空分布をnullにし、回帰試験を追加。失敗時の実行記録も保存し、初回成功のように書き換えない。

時間順の緩慢な変形も代表を増やせるという構造的制約は残る。現在の計数だけから「初期松弛ではない発見」と認定しない。負の結果を解消するために解析後に別のアルゴリズムへ変更していない。
