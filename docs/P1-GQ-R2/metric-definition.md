# 局所構造領域の操作定義

本資料の数値パラメータは PROPOSED、解析値は別表の MEASURED/DERIVED。生物学的な状態数を定義したものではない。

## 構造と距離

残基順に並べた28個のCα座標を r_i(x) [Å] とする。P={(i,j):1≤i<j≤28,j−i≥3}、|P|=325。D_ij(x)=||r_i(x)−r_j(x)||₂、d(x,y)={Σ_P[D_ij(x)−D_ij(y)]²/325}^(1/2) [Å]。末端や近接残基だけの変化を弱める一方、全体の曲がりやドメイン間変化にも反応するため「局所」は探索対象範囲を意味し、局所原子だけの記述子という意味ではない。

剛体変換に不変だが鏡像も区別できない。側鎖手性の別検査が必要。全原子同一性・ペプチド鎖順序・非周期系という前提がある。二つの構造が同じdを持つことは同じエネルギーや動力学状態を意味しない。判定は d>ε+10⁻¹⁰ Å。許容差はdouble演算境界用でありDCDの物理精度ではない。

## A：逐次的な幾何領域

既往代表集合R、任意の共通履歴A₀に対して m(x)=min_{z∈A₀∪R}d(x,z)。A₀は全適格履歴点の集合をそのまま使用する。R2内の単一系列の記述ではA₀なしで最初の適格点を種代表とする。

m(x)>εで仮代表cを置く。以後、適格でm(x_t)>εかつd(x_t,c)≤εの連続支持がτ psに達すればcを登録する。既知領域への復帰、ε外への移動、不適格フレーム、標本化間隔の1.01倍を超す欠落で支持をリセットする。新候補は最初の点に固定され、平均化しない。同時刻の複製はτを増やさない。τ=0のとき即登録する。

N_A=登録代表数、ΔN_A=N_A−1（種代表なしの共通履歴モードではN_Aが追加数）。代表間隔>εは保証するが、全領域の互いの分離や、全フレームのε被覆は保証しない。τ>0では一時的に通過した構造を被覆しない。ε球の重なり、入力順序、τ・標本化への依存がある。熱揺らぎ、準安定状態、科学的発見を自動分類する方法ではない。

## B：固定参照庫

校正系列11→12の100 ps以降を2 ps間隔で、τ=0の貪欲法で構築した固定庫L_ε。各点を最近傍代表に割り当て、距離≤εのみ庫内とする。同距離は固定代表順の最初を採る。

V_B=|{argmin_{c∈L}d(x,c):min d≤ε}|、O_B=Σ1[min d>ε]/n。V_B/|L|はこの有限庫の被覆であり全構象空間の被覆率ではない。庫外フレームの比率・距離を保持し、それぞれを別状態に数えない。構庫系列と別系列を必ず区別する。

## 補助記述子と単位

Cαの等重み回転半径 Rg=sqrt(Σ_i||r_i−r̄||²/28) [Å]。これは全原子質量重みRgではない。接触専用の集合 P_Q={(i,j):j−i≥4} は300組であり、Q₈=Σ_{P_Q}1[D_ij<8 Å]/300。dRMSDの325組とは異なる。既存実装の境界は厳密に `<`、連続値や天然接触率ではない。

主鎖54角について δθ_k=atan2(sin(θ_k(x)−θ_k(y)),cos(θ_k(x)−θ_k(y)))、a(x,y)=sqrt(mean δθ_k²)×180/π [度]。角度を単純に引かない。dとaは異なる座標表現だが同じ構造由来であり統計的独立ではない。

## 将来の等MD量・等壁時計比較

入力契約：同じ履歴ID/原子対応/品質規則、A₀、ε、τ、標本化、将来フレームID、MD物理時刻、公開時刻、資格確認時刻。各枝を同じA₀と空のRから開始する。等MD量のY(q)と、公開・資格が期限H内に確定したY(H)は別の推定対象。期限後フレームでτ支持を満たして期限内成果に戻し入れない。

本実装の `published` は公開と資格の両方を満たした利用可能時刻を呼出側で作成して渡す。待ち行列・ファイル公開を自動観測する実装ではない。CのXは決定前、Yは将来MD。共通記述子の機械的関連を開示し、角度診断などを併用する。今回この接口のみをテストし、B/C実験は行わない。

時間は保存点で離散観測するため、τ=5 ps・間隔2 psでは最短6 psの支持が必要になる。間隔5 psなら最短5 psとなる。全て同じ連続時間を厳密に観測したとは主張せず、この量子化を標本化感度に含める。種代表だけは履歴の基準点として即登録し、支持によって得た追加数から区別する。
