# 修正・失敗記録

2026-10-26。原データ、MD条件、事前候補尺度を変更していない。

1. 全フレーム品質検査はanalysis-v1で成功。以後の描画を日本語化し、代表間角度差・登録時刻を保存するメタデータを追加した。品質実行時ソースをquality-source.pyとして保存し、後続ソースとのSHAを区別する。
