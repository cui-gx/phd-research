# 統計単位と妥当性の限界

32,000フレームは32,000回の独立実験ではない。4本は同じunfolded準備構造から異なる速度・確率流で生成した系列であり、準備条件に関して独立ではない。1 ns後のcheckpoint延長は同じ系列である。時間ブロックを独立campaignとして扱わず、フレーム単位の狭い信頼区間やp値を出さない。

11/12は閾値の探索的校正と構庫に使った。13/14もR1で既に確認済みであり、盲検・外部検証ではない。系・力場・初期準備・記述子を変えた普遍性は評価していない。主解析と感度表を全系列について報告し、有利な系列を選ばない。

Rgの自己相関・最初の非正相関時刻・その手前までの積分値は有限・非定常系列の記述に過ぎない。平衡性、独立サンプル数、必要実験数を認証しない。構造間距離の多数の組も同じ点を共有する。誤差帯を作るためにそれらを独立とみなさない。

時間順ε-netの領域数は客観的な状態総数ではなく、固定尺度での操作的な幾何多様性である。微細なεでは熱揺らぎを数え、粗いεでは異なる構造を併合し得る。τの導入は物理的寿命や遷移障壁の推定を意味しない。初期の一方向松弛、長時間ドリフトでも新領域が増える。

未来の確認には、現在データと混ぜない新しいMD系列、準備履歴の明記、事前に固定した尺度・品質・除外・時間規則、同一履歴からの枝比較、祖先単位の開発/評価分離が必要。必要本数・長さ・GPU予算は本輪で認定せず、研究者が別途審査する。

基礎資料：[Grossfieldら、分子シミュレーションの不確実性と標本化](https://pmc.ncbi.nlm.nih.gov/articles/PMC6286151/)。本輪はこの指針に沿って相関と初期過渡を開示するが、指針自体が本輪の閾値を保証するわけではない。
