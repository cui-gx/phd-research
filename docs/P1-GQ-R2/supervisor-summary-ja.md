# 指導教員向け概要：局所構造探索の評価資格

## 研究目的と本輪の位置づけ

P1は、限られた単一GPUでMDとCVAE学習・推論をどう実行すれば、局所的な構造探索に有効な計算が増えるかを調べる研究です。FSD-EY（1FME）は評価対象であり、蛋白質の折り畳み機構や新しいCVAEそのものの研究ではありません。科学的フィードバック状態の追加情報をC、更新後の効果と実費用をBとして検討していますが、今回その効果実験は行っていません。

今回の課題は「探索が増えた」を何で測るかです。GQ-R1で取得したNoCutoffの4系列×4 ns、計32,000フレームだけを用い、サーバCPUで解析しました。GPU計算は追加していません。

## 実施内容と結果

全フレームの拘束・ペプチド幾何・重原子近接・相対手性を検査し、登録した粗い異常条件では除外0でした。ただし初期準備や平衡化が正しいことの証明ではありません。

評価は、325組の非局所Cα距離の差を使う増分領域法Aと、別の校正系列から作る固定参照庫Bを比較しました。解析前にε・持続時間・標本化・緩和除外の候補を登録し、1,536条件を全て保存しました。

Aでは100 ps除外、2 ps間隔、5 ps支持、ε=2 Åの追加領域数が25/37/26/32でした。しかしε=0.5 Åでは支持がほとんど成立せず、1 Åに緩めると71–105領域となりました。細かい尺度ほど多く探索を数えるという単純な関係ではなく、εと支持時間の組合せが結果を左右します。

Bではε=2 Åの参照庫に対して別系列13/14の庫外率が約99%/100%でした。4 Åでは約5%/46%ですが、粗くして庫外率を下げることは物理的な妥当性の認証ではありません。

重複・剛体変換・人工異常などの9プログラム試験は通過し、小標本の厳密距離とも一致しました。主要6実行は失敗1件を含み約152秒、ピークRSS約0.26 GiBで、計算可能性は確認しました。

## 判断と相談したい点

工学的な評価器は納品できますが、唯一の科学成果指標としての資格は **NOT READY** です。局所形状差は観測される一方、短時熱変動・初期松弛・意味のある領域変化を区切る尺度を、この既知4系列だけで確定できていません。フレームを独立実験数として扱ってもいません。

次に必要なのは、準備履歴・質子化・暗黙溶媒の適用を確認し、新しい独立条件で尺度と時間規則を固定できるかを審査することです。現段階では正式なCVAE更新効果比較を開始せず、研究者と計画側の判断を待ちます。S3は未承認、過去のS2補充独立終審も未完のままです。
