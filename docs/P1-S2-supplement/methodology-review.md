## 3. 对A的审查结论

固定 `(Rg_CA,Q_long)` 与 `(Rg_CA,R_ee)`具有直观物理含义，但都是有损投影。Rg使用等权Cα而非全原子质量；Q是所有预定长程对的接触比例，不是native contact Q。避免借用“Q”而暗中把native信息带回评价器。`analysis-plan.md`固定配对定义、单位、箱宽、原点、边界、全网格及内部旗标；这些阈值是工程/方法诊断约定，不是已被文献标定的热涨落容差。

Whole-seed r0→calibration、r1→内部holdout是当前最少泄漏的有界方案。r1已曾出现在S2总体汇报，只有一个新留出组，不能标成严格未见过数据或外部验证。主结果不汇总三种长度同seed的重复路径；长度成本本身仍是三次真实任务测量。即便前缀不逐位一致，数值非确定性也不创造独立随机实验。

dRMSD中心库的中心只能来自r0预定5ps抽帧，在r1前固定；对r1库外构象报告距离/比例而不在线增中心。这消除了“探索多少就增加多少评价状态”的循环定义。但有限校准库会遗漏新区域，`visited/K`只衡量校准库访问率，不能是全部构象空间覆盖百分比；库外样本不自动成为彼此独立的新科学状态。低维投影/距离表示可能混叠形状，dRMSD对镜像不敏感，这些需列为固有限制。

对负对照的正确期望：重复和置换不改变最终集合；置换可以改变累计首次发现时间；抽稀可以减少覆盖，不要求完全不变；旋转/平移只应有浮点边界敏感性。把这些情况都机械要求“完全不变”会制造错误测试。两个seed只能描述差异，不能用帧级自助法或独立样本p值制造可信度。

## 4. 对B的审查结论

官方sklearn1.6.1定义的 `negative_outlier_factor_` 越小越离群；应排序全部候选上的该属性，不能把 `novelty=True` 的新样本接口与现有fit池分数混用。[官方定义](https://scikit-learn.org/1.6/modules/generated/sklearn.neighbors.LocalOutlierFactor.html)

源码显示mdlearn公共fit按split_pct拆train/validation、drop_last=True，并在每epoch验证；相同epoch不等于相同optimizer steps，随机划分也消耗RNG。因此补充计划明确使用固定200步的vendor训练逻辑而非据epoch推断，F1旧400重复2次/F2旧400+新400，共800训练曝光，恢复模型buffers与RMSprop完整状态。验证不是为选优模型，所有结果保留。新增CPU的F0与F1/F2用同平台推理，旧CUDA结果另列。

这能缩小“训练更新量”混杂，却仍只是单个旧/新数据配对上的数据组成干预；数据分布、独特构象数、轨迹seed都随“new”改变，不能识别抽象的纯新增数据数量效应。三个训练RNG配对只检验优化随机性的描述性稳定性，不是三个独立科学workflow。共同checkpoint本身仅训练1epoch，LOF变化可能反映未收敛表示，变化大也不必然更好。若F1与F2同样变化或完全不变，应保留阴性结果，不增加训练直到出现期待信号。

合格结论只能是“在这些固定输入和受控更新量下，是否观察到候选决定变化及本机开销”。没有后续等预算MD对照，任何“AI促进探索”“值得花GPU时间更新”或“某时序更优”均不支持。
