# P1 S2補足検証：指導教員向け研究概要

2026年10月25日。対象：FSD-EY（PDB 1FME）、OpenMM、既存mdlearn CVAE。正式な計算資源はRTX PRO6000 Max-Q96GB 1枚ですが、**今回は保存済みデータを使ったローカルCPU検証のみ**です。新しいMD計算やGPUによるスケジューリング比較は行っていません。

## 目的

限られた計算時間の中で、MDを続けるか、AIモデルを更新して次の開始構造を選び直すかを比較する前に、科学的な評価方法と計算条件を確認します。今回は「モデル更新で探索が改善する」と証明する段階ではありません。

## 方法と確認できたこと

事前に解析計画を固定し、既存4,880フレームを確認しました。主解析は異なる二つのMD乱数シードの1ns軌跡各1本です。同一軌跡内のフレームを独立な反復とは扱っていません。

**構造の評価**：Cαの回転半径と長距離接触割合を固定幅で区切ると、訪問した区画は二つの軌跡で6個と11個でした。従来の「ほぼ各フレームが別状態」という問題は避けられました。ただし、同じ区画にも異なる構造が含まれます。一方の軌跡から作った固定構造中心集合では、他方の軌跡の85.8–99.8%が集合の許容距離外でした。この中心集合は正式な被覆率の評価器としては不十分です。

**天然構造を使わない候補選択**：同じ800候補にCVAEとLOFを適用しました。共通の重み・最適化器状態から、旧データだけで追加学習する条件と、新旧データを混ぜる条件を、いずれも200更新・800サンプル提示に合わせました。三つの学習乱数シードで、上位100候補の共通数は23、28、28、最上位候補はいずれも変わりました。旧データだけの追加学習でも候補は変わるため、単なる追加学習の効果と新データ構成の効果を区別する必要があります。これは**候補選択の変化**であり、その後の探索改善を示す結果ではありません。

**MD条件**：事前指定の11構造について、1nm、2nm、NoCutoffでエネルギーと力を評価しました。132回の状態取得を行い、MD積分は0ステップです。1nmとNoCutoffの全原子総力の相対L2差は約0.17–0.22%でしたが、33条件中12条件で事前設定の数値再現性警告を検出しました。また、総力には結合力が含まれ、NoCutoffも物理的な真値ではありません。小さい相対差のみを根拠に科学条件の妥当性を認定しません。
