## 1. 验证问题与必须回应的假设

RQ-A：以哪些**预定义、物理可解释**的固定结构特征及尺度衡量 1FME 的构象空间探索？怎样避免旧325维完整特征几乎每帧记为新状态（4,880帧/4,859个指纹）的失真？

RQ-B：排除已知 folded/native 参考结构参与候选决策后，原 mdlearn CVAE/LOF 的 frozen/updated 模型是否仍引起候选变化？需要分清「增加训练迭代」和「新增 MD 数据」。

RQ-C：对 FSD-EY 的实际 1FME unfolded 输入、GBn2 隐式溶剂、1nm cutoff、非周期接触与重新起始 MD 处理，有何经过证据支持的合格边界、待验证物理假设和建议的最小修正？

RQ-D：完成 A/B/C 后，哪些项目足以冻结为今后 S3 的正式比较协议，哪些依然需要独立数据和科研用户批准？

2. 复核 S2 已有原始结果及 manifest/种子/软件版本/哈希；明确哪部分原始轨迹或权重**只能在本地或个人服务器读取，未上传 GitHub**。若缺失则记录 `UNVERIFIED`，不得猜测。
3. 仅有两条各长度不同的 MD 种子不代表足够的独立统计重复；同轨迹的相邻帧高度相关。对于阈值选择可预先按整条 seed 轨迹或预先确定的大时间块拆分 calibration / holdout，报告跨块相关性及数据泄漏风险；如果缺乏真正独立数据，只能给候选和内部检验，不得宣称外部验证完成。
4. 所有分箱/阈值、坐标、单位、距离计算、是否时间抽稀、是否包含平衡前帧的选择均可追溯。制定有条件的敏感性分析，但不得事后择优只呈现一种结果。

## 3. A：构象覆盖评价方法的离线收敛（最高优先级）

**A1 — 固定低维物理状态覆盖**

- 至少研究一个物理解释清晰的二维/低维表示，例如 `R_g`（回转半径，Å） × `Q_{long}`（长程 Cα 接触数/比例，预先固定序列位置分离与接触距离）；或 `R_g` × 端到端 Cα 距离。指定精确公式、单位、原子集和边界。
- 用**先验物理尺度或独立 calibration 数据**预定义固定分箱/锚点，不允许所有正式测试数据共同拟合区间再用于证明策略差异；明确范围外状态、边界计数与漏计的处理。
- 报告 visited cells 随**端到端墙钟**、已采样物理时间 ns 和轨迹帧数的轨迹；指出二维投影可能混合高维不同构象，不把 cell 数直接当作独立稳定态数量。

**A2 — 可选独立新颖性评价**

- 在固定 Cα 距离特征上比较一种有预先定义尺度的 dRMSD / 距离度量与固定参考中心库或新颖性容差；中心库需来自事先固定、与未来策略比较隔离的数据。若只有 S2 数据，则只形成内部可行性候选，明确不能作为已外部验证的正式统计判据。
- 说明构象对齐、维度、距离归一化、去重定义、对同一物理构象旋转平移与测量噪声的稳健性；固定库建成后不得因为某策略获得更好覆盖结果而重新训练/更新。

**A3 — 必需的压力测试**

- 同一输入重复 2×不应增加已访问状态；相同轨迹的抽帧（0.5/1/2/5ps 或现有可实现间隔）应展示尺度敏感性，不能以“原始状态数随帧数增长”冒充新颖性。
- 描述每段轨迹的时间相邻自相关/连续停留/状态跳变；对不同 seed 的观察差异如实报告，小样本只做描述性结果，不求夸张显著性。
- 对合理的小范围固定阈值网格展示结果的敏感性，不要为了避免饱和而保证“好看”的状态数；如果任何定义仍退化，记录 FAIL 和所缺独立数据。
- 用一组相同数据做负对照（重复、置换顺序、刚体旋转/平移、时间稀疏化），验证评价器的合理不变性；不得通过随机扰动人为创造科学状态。
- 结论只选**推荐候选**和为何尚需独立验证；除研究者另行批准，不自动冻结最终主指标。

交付：`coverage-methods.md`，至少一个可复现表格/图，`coverage-sensitivity.csv/json`，包含数学公式、阈值预注册与校验记录、合理性检验和不通过情况。

## 4. B：无天然参考信息的候选选择与训练对照

1. 完全保留原始 DeepDriveMD / LOF → folded-reference RMSD 的复现输出和历史证据，不覆盖老结果。明确其不适合无监督探索的 oracle/参考泄漏风险。
2. 在相同的固定800帧候选池比较：
   - 现有参考引导结果（仅作说明/复现对照）；
   - `CVAE embedding → LOF` 的纯离群候选规则（必须固定极值方向、稳定 tie-break、是否对所有帧做 LOF 和噪声筛除）；可附物理表征选择为另一候选方案，但不自动改变正式工作流。
3. 记录冻结/更新模型选中原始 `trajectory_id + frame_id`、top-k重合、Jaccard、排名相关、选中构象间的独立物理距离、额外训练与推理 wall-time、种子/权重/候选池哈希。所有候选规则完全确定且对照使用相同候选池。
4. **分离更新训练步骤与新数据**：优先做三臂有界离线比较，例如 `F0`（冻结旧checkpoint）、`F1`（在旧400帧继续相同epoch）、`F2`（旧400+新400帧继续相同epoch）。保持共同初始checkpoint、学习率/optimizer与随机性，记录新增帧与优化batch步数不同的混杂；若要识别纯新增数据效应，应匹配实际 optimizer steps 而非只匹配epoch。若无法在已批准CPU/现有资源内可靠执行，应只提交正式实验设计与估算，不能偷偷多跑长GPU计算。
5. **只回答是否改变决定及可量化开销**；不运行“不同选择导致的后续收益”MD比较，不宣称现在已证明CVAE促进构象探索，不宣称单例影响具有统计普遍性。

交付：`selection-audit.md`、`selection-comparison.csv/json`，说明每项因果比较能说明与不能说明的结论。

## 5. C：MD 物理协议与输入链剩余风险的证据化处理

1. 逐一核对已有 1FME input manifest、上游固定 commit、NMR MODEL 1 与 unfolded 的制备记录是否可从**原始代码/一手文献**确定。无法找到的步骤明确 `UNVERIFIED`，不可补写臆测的热展开、平衡或质子化历史。
2. 对 unfolded 准备、势能最小化、初始速度、Langevin 热浴、burn-in/equilibration、restart/reseeding 语义给出不依赖“只看平均温度接近300K”的科学审计。后续用于探索的轨迹不得在没有证据时宣称平衡或转移动力学无偏。
3. 非周期 OpenMM GBn2 与 PDB 中 CRYST1 盒子语义分开：保留 S2 的 `4,880/4,880` 有盒/无盒接触图相同事实，解释为何仍应在正式数据处理中明确采用非周期距离；不要宣称已经污染数据。
4. 依据 OpenMM 官方一手文档及锁定的软件版本，比较 1nm、2nm、NoCutoff 对**相同有限构象快照**的势能、逐原子力差（用明确单位、最大/中位/分位点或适当归一化）、CPU计算时长或已有可用实测成本。若程序实际支持且许可明确，可做小规模非积分 CPU evaluator 验证；明确改变力场截断的比较是敏感度试验，不属于已批准的新正式MD协议。
5. 总结若正式协议要更改 cutoff / burn-in / 输入来源，会破坏与S2现有基线的哪些直接比较，建议如何保持科学公平；提供可审计的建议，不擅自大规模重算。

交付：`science-readiness.md`、来源表（URL/版本/commit/页码或章节）、`physics-sensitivity.csv/json`（实际可测才输出）和未确认风险登记。

## 6. 质量、报告与证据门槛（必须）

报告应能让导师或不参与编码的审阅者**不依赖口头解释**理解实验：

- 摘要（可附200–300字日语研究概要）、明确的研究问题、已确认的科学目标及本阶段结论范围。
- 研究设计：输入结构来源、版本、FSD-EY物理设置、固定实验条件、对照定义、测量边界、假设与失败准则。
- 数据与复现：完整相对路径、独立代码提交 SHA、软件锁版本、每条可计算结果对应的真实证据文件/哈希/随机种子，是否在GitHub、个人服务器或本地。
- 结果：一手量化表/可复现图、样本量以**独立轨迹**而不是frames为统计单位、必要敏感性分析；区分`MEASURED`（证据支持）/`DERIVED`（计算推导）/`PROPOSED`/`UNVERIFIED`。
- 不确定性：不滥用置信区间或p值；当前少量、强自相关的轨迹一般只能给描述性分析；比较模型变化时不把“多训练一步”和“加入数据”混为单独因果影响。
- 威胁有效性（threats to validity）：计算资源共享、科学模拟物理、方法学数据泄漏、筛选规则泄漏、评价指标退化、缓存/启动时间与采样间隔。
- 反例/失败记录及解决过程不能删除；记录哪些负面结果依旧未解决；清楚写出“现有证据不支持什么”，不允许把尚未验证的科学收益写成已发现成果。
- 同时给一页`supervisor-summary-ja.md`（导师可阅读的日语摘要；正文可为中文/英语），但日语摘要仅复述有凭据的事实，不自行加工结论。
- 每个主要结果提供可独立查阅的证据链接/路径，做到复核者可从总结数字回溯到原始数据及脚本。大型原始轨迹、权重不进 GitHub，记录安全受控的实际留存地点和校验摘要。
- 对第三方科学事实优先引用OpenMM、PDB/RCSB、DeepDriveMD、mdlearn 的一手文档/固定源码及可信文献；区分“原仓库配置”和“科学上已被验证”。
