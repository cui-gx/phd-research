# 共通候補選択

全モデルが同じ7,800適格フレームを同じ順序で推論する。既存mdlearn `predict`、推論batch64、seed2026102671、LOF neighbors20/Minkowski p2/novelty=False/n_jobs2を使う。negative_outlier_factor_の小さい順、同値はglobal frame IDの小さい順。先頭1点を選び、全順位・embedding・score・Top10/100を保存する。天然参照RMSDによる再順位付けはない。

下流開始前に固定した選点は以下。IDは共通4 nsの0起点保存frameで、時刻は公表ログの実値を最終証拠で確認できる。

| モデル | 選点global ID |
|---|---:|
| F0 | 3117 |
| F1 ブロック1 | 3123 |
| F2 ブロック1 | 894 |
| F1 ブロック2 | 1922 |
| F2 ブロック2 | 1388 |
| F0 再推論 | 3117 |

F0の再推論はembedding/LOF/全順位を含め完全一致した。F1/F2は各ブロックでweight/optimizer/初期RNG/200歩/800曝光の一致検査を通過した。ID差は実測だが、近接した時刻のID差が大きな構造差を意味するわけではない。Top-k重複・順位相関・dRMSD/周期主鎖角を最終選点比較で併記する。

選点がすべて旧区間に属すること自体は異常ではない。新データでモデルを更新する処理は、必ず新データの構造を選ぶ処理ではない。下流MDが改善するかは別の測定対象である。
