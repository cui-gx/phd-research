# 統計と解釈の限界

最上位の共通歴史は1つ。二つの対応乱数ブロックはこの状態に条件付けた探索的繰返しであり、独立科学状態は2つではない。各ブロックで学習seedとMDseedがともに変わるので、学習由来とMD由来の分散を分離できない。

48,000の下流保存フレームや各prefix/除外条件を独立反復数にしない。フレームbootstrapで狭い区間を作らず、p値・統計的有意差・一般的な効果量の確定を主張しない。相関は時間診断として示す。二つの対応差が同符号でも一般性を証明せず、符号が違えば不一致をそのまま報告する。

validationは同じ歴史の時間splitであり未知campaignの性能ではない。候補poolと学習データが重なるのは本オンライン設定の一部で、選点差をモデル汎化精度と呼ばない。初期準備、NoCutoff/GBn2、短時間の座標reseed、科学proxy尺度を固定した条件付き結論である。

F2−F1は固定200歩/800曝光のもとでデータ組成を変えた総効果。旧/新の分布、重複特徴、時刻等もその干渉に含まれ、新データの純粋な情報量だけを分離した効果ではない。F1−F0は追加最適化、F2−F0は複合更新の差である。

B1は全枝4 nsに揃え、学習で失うMD機会を差し引いていない。測定された更新時間が短くても、固定壁時計の純利益やCの状態情報増分はまだ証明しない。一状態の平均的な効果が正/負/ゼロであることから状態依存性を推論しない。

準備史/pH/十分な緩和、dRMSDとτの尺度、2 ps観測、有限履歴A0の代表性、GPU数値再現性、シリアル実行/冷起動費用がThreats to Validityに含まれる。共有資源の事前検査でも外部変動を完全に消せない。陰性や不一致を実装失敗と扱わず、正式な拡大前に独立状態と反復設計を審査する。
