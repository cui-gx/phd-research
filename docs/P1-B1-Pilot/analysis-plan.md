## 代理指標の固定

連続代理：325組（配列間隔≥3）のCα距離 d(x,y)=sqrt(mean(D_k(x)−D_k(y))²) [Å]。同じA0全点へのd_minを全保存0.5 psで計算し、平均/中央値/p90、100 psブロック/分布を保存。最大値のみで判断しない。

離散代理：R2の増分ε領域をそのまま再利用し、ε=1.5/2/3 Å×τ=0/5 ps、間隔2 ps、各除外/各prefixで全出力。A0全点と新代表の双方と重複排除。共通履歴があるので新しい種を無料で数えない。ε/τ/順序の制限と5 ps→2 ps観測では実質6 ps支持になることを開示。最近傍のキャッシュは同じA0 SHAに結び、厳密小標本と照合する。

補助：等重みCα Rg [Å]、配列間隔≥4の300組で8 Å未満の接触割合Q8、周期phi/psi差、品質、時間相関。CVAE latentは選点診断にのみ使い成果の採点に使わない。全て探索的幾何代理であり自由エネルギー/生物学的発見価値ではない。

各ブロック/各尺度/各prefix/各除外で三条件と三つの対応差を保存。主表示は4 ns・100 ps除外、連続平均/中央値/p90と全6離散条件を併記。指標を合成せず不一致を報告。二つの乱数ブロックと単一共通履歴では有意差/状態一般性/学習とMDの分散分離を主張しない。符号不一致やノイズとの区別不足はINCONCLUSIVE。
