# 事前固定された探索的物理代理指標

唯一の絶対的構象指標を認定する課題ではない。以下の全指標を事前に固定し、結果が不一致でも保持する。潜在距離や学習lossで各臂自身を採点しない。

## 連続幾何新規度

28残基のCα座標r_i [Å]に対しP₃={(i,j):j−i≥3}、|P₃|=325。

D_ij(x)=||r_i(x)−r_j(x)||₂。

d(x,y)=sqrt[(1/325)Σ_{(i,j)∈P₃}(D_ij(x)−D_ij(y))²] [Å]。

共通履歴A0は決定時に公開済みで品質条件を通過した100 ps以降の4 ns全体。m(x)=min_{h∈A0}d(x,h)。全枝で同じA0 SHAを使い、後から各臂の履歴を追加しない。mの平均/中央値/p90と全分布、100 ps窓を保存する。主表示は下流4 ns、100 ps除外。感度は0/200/500 ps除外、prefix1/2 ns。大きいmは既往履歴から幾何的に遠いことを意味し、有益な生物学的発見や自由エネルギー差を意味しない。

## 多尺度の増分領域

R2の固定仮代表アルゴリズムを使い、m_R(x)=min_{h∈A0∪R}d(x,h)>εで新候補を作る。ε=1.5/2/3 Å、連続支持τ=0/5 ps、間隔2 ps。既往全点と新代表の両方で重複排除し、共通履歴があるので最初の点を無料の種として加えない。

登録代表と確認時刻を保存する。間隔2 psではτ5 psの最短観測支持は6 ps。既知領域への復帰、候補からε外への移動、不適格/時間欠落で支持をリセットする。τ導入の非単調性と入力順序依存はR2の既知の制約として保持する。確認的な準安定状態数とは呼ばない。

最近傍mは同じA0の全点で一度だけ計算・SHA付き保存し、各尺度で再利用する。元R2関数に任意の事前計算距離入力を加えただけで、既存APIの挙動は維持する。小標本で厳密式/分割距離/従来history入力との一致を検査する。32,000²の無制限行列を作らない。

## 独立座標表現による補助診断

Rg=sqrt(mean_i||r_i−r̄||²) [Å]は等重みCα回転半径。Q8=Σ_{j−i≥4}1[D_ij<8 Å]/300、天然接触率ではない。54主鎖角の差は周期的atan2(sin差,cos差)を用いRMS [度]とする。未来構造とdRMSD最近傍履歴の主鎖差も併記する。これらは別表現だが同じ構造由来で統計的独立ではない。

剛体不変でもdは鏡像を区別しない。全原子手性/幾何の保守的品質規則を併用する。元準備の絶対的妥当性や十分な局所緩和は未認証。大きい距離、領域数、低Rgのどれも単独で「より良い蛋白構造」と解釈しない。

## 対応差

同じ単位の各YについてΔ21/Δ20/Δ10をブロックごとに算出し、連続量と領域数を相互に足し引き・合成しない。最もF2に有利な尺度を唯一の結論に選ばない。物理幾何代理の因果的な決定効果と、科学発見価値の認証は異なる。
