# 下流MDの実行条件

三条件×二対応乱数ブロック、各4 ns、合計24 ns。共通履歴4 nsをこの量に含めない。全枝で同じNoCutoff/Amber14-all/GBn2、温度/摩擦/刻み/拘束/精度/保存間隔を使い、System XML SHAが既定GQ候補と一致することを検査する。

選ばれたDCDの全原子座標を抽出し、その.npy SHAとsource DCD/frame ID/モデルSHAをMD要求に記録する。実際のContextへの投入前配列は `initial-coordinates-A.npy` に保存して厳密一致を検査する。PDBの表示丸めを経由して座標を読み直さない。全枝で同じ最小化（10 kJ/(mol nm)、maxIterations1000）と300 K速度reseedを行う。下流枝は連続checkpointではない。

MDseedはブロック1=2026102691、2=2026102692。順はブロック1のF0/F1/F2、ブロック2のF2/F1/F0。各タスク前の共有CPU/メモリ/GPU確認、プロセス帰属確認、単体1800秒/RSS16 GiB監視、完全回収を行う。F2が不利なことを理由に延長/再実行しない。

各8,000フレームを全点品質検査する。生4 nsは保持し、主解析100 ps除外、感度0/200/500 ps、prefix1/2/4 ns。末尾だけを拾わず、100 ps時間窓も報告する。最小化後座標の独立ファイルは保存していないが、同じ初期配列・実行ソース・System・最小化条件を追跡できる。初期再緩和による効果を完全に除去したとは主張しない。

幾何異常検出条件はR2と同じ保守的条件。手性は準備構造との相対比較で、pH/初期絶対配置や力場全体の科学認証ではない。全角を単純なRamachandran許容箱で排除しない。品質違反・欠損・失敗は保存し、実験条件を黙って除外しない。
