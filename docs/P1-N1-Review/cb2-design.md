# CとB2の最小検証設計・N1後の更新案

**全てPROPOSED、実行NOT APPROVED。** 2026-10-30。旧[N1案](../P1-N1/cb2-minimal-design.md)の64rollout/600秒/4校正根＋8未知根は費用の仮案として保管する。本書はその科学的十分性を認めず、資格を段階に分ける。新しい主成果、配方、根数、時間は研究者が採択して初めて実行仕様になる。

## 1. 目標と推定対象

同じ準備系・GPU・固定科学レシピの有限時間サンプリングを対象にする。native評価はオフラインだけで、モデル入力・LOF・X/Z/W・行動には与えない。成果候補は、共通の決定前履歴Aと、H秒までに利用可能になった品質適格新frameを使う

\[
B_\pi(H)=\min_{x\in A\cup A_{\pi,\mathrm{new}}:\ t_{\rm available}(x)\le H}r_1(x),\quad
G_\pi(H)=B(0)-B_\pi(H)\quad[\mathrm{Å}].
\]

新しい適格結果がなければG=0。履歴を再選択しただけの利得を防ぐ。native hit閾値を必要としない有限構造進捗であり、折り畳み成功、全構象被覆、平衡の主張はしない。model1を主候補、Q1・RMSD分布・元幾何量・品質除外率・有効MD量を補助として残す。NMR34は事後感度で、勝つ参照への切替えに使わない。最小値の一過性に対して平均/中央値/Qが逆行する場合は明示する。

**Cのラベル**：同一決定状態sからUPDATE_NOWとSTALE_NOWを分け、同じHの全費用を課金した

\[V_{s,t,m}(H)=G_{U,s,t,m}(H)-G_{S,s,m}(H)=B_{S,s,m}(H)-B_{U,s,t,m}(H).\]

正が更新有利。最初の一判断だけを変え、以後の更新はせず、同じ固定長MD/選点規則で展開する。STALEに訓練seedは不要なので同じS枝をtごとに実行し直さない。目的は条件付き期待値v(s)=E[V|s]の予測であり、一つの乱数差を真のvと呼ばない。Uには新旧データ置換と追加最適化の双方を含む。F1対照のない最小Cは新データ単独の因果寄与を識別しない。

**B2の効果**：複数判断を含む方策実行の根内差

\[D_r^{B2}(H)=\overline{G_{ZW+X,r}(H)-G_{ZW,r}(H)}.\]

科学情報の予測誤差減少と、特徴計算の費用を含む実成果改善は別である。Cが不成立でも費用だけの良いスケジューリングがあり得る。Cで情報があっても費用・誤判断でB2利益が消え得る。

## 2. 情報条件：強いZ/Wを維持する

旧[B1状態定義](../P1-B1-Expansion/state-dependence-analysis.md)ではWにRg、Q8、既訪問投影、最近反復率を含む。ZWを純機械情報へ縮小しない。

|集合|合法な候補情報|採用前に確認すること|
|---|---|---|
|Z|残時間、完了MD量、候補数、訓練旧/新数、親モデルage/steps、過去の実費用・費用予測|時点・単位・遅延を固定。今実行する更新の未来実費を入力しない|
|W|既存のRg/Q8要約、過去幾何被覆、最近反復率、ワークフローの公開状態|元の強い物理/履歴要約を維持。Xとの重複を辞書で明示|
|X（最小案）|固定個数のNEWに対するOLD内部距離の平均新規度X1 [Å]|既存の合法時刻のデータだけ。native r/Q、更新後loss/候補/効果は不可|

X1は `mean_(x∈NEW) min_(h∈OLD) ||d_P3(x)−d_P3(h)||/sqrt(325)`。OLD/NEWの抽出数・窓・品質・IDを結果前に固定し、全候補×全履歴の無制限計算にしない。既存800点学習membershipは開発候補で、正式特徴用の集合とは採択前に区別する。X1の算出時間、保存量、初回読取りとcache費用は有料。Wから正確に復元できるXは独立な増分と称さない。

最小比較は**同じS4決定時刻、同じ候補数/窓規則、同じ親作成規則、同じH**で行う案である。S4とS8をXの高低群として代用しない。候補の実内容は根により異なる。同じZ/W領域でXのばらつきがなく、Xが段階を識別するだけならNOT_IDENTIFIABLE。共通支持は各特徴の1次元range交差だけでなく、組合せ・近傍・共線性・根外予測範囲を開発資料で点検する。分布外でのみ利益が見える場合は一般化を留保する。

## 3. 予測器の対照と評価

最小候補は標準化した低容量の正則化回帰、ZWとZW+X1に同じ学習法、同じ候補正則化集合、同じroot分割を用いる。標準化、欠測補完、特徴選択、λ選択はtraining根内だけ。ZWを調整しない固定定数にし、X側だけ十分調整する比較は禁止する。実装前に特徴schemaとモデル自由度を凍結する。

4校正根は多変量回帰・閾値選択・独立validationを同時に成立させるには少ない。4根で得た係数を高精度予測器と認定せず、(a)既定の物理費用則を固定し少数係数だけ試す開発診断、または(b)根を増やす別計画、を研究者が選ぶ。根内frame/seed数を増やして見かけの学習nを水増ししない。

C主評価候補は未知根ごとのMAE差 `MAE_ZW−MAE_ZWX` [Å]（正がX有利）、補助RMSE/較正、全根誤差と符号。予測対象は繰返し平均Vだが測定雑音を併記する。符号正答率だけを使わず、V≈0の区間と効果量を保つ。独立根以外へまたがるランダムframe splitは禁止。データが不足する場合は探索的推定に留める。未観測の反実仮想をモデル予測で「実測ラベル」にしない。

B2のZW/ZW+Xは同一action U/S、同じ更新recipe、selector、候補生成規則、admission/deadline処理を持つ。`predicted V > 0`などの発動則も開封前に固定する案。X計算時間を含むHに合わせて学習・費用模型を定義する。CラベルをX計算が無料のt0から作ったなら、そのまま費用込みB2のラベルとは呼ばない。Cは情報評価、B2でXの実際の観測待ちを払うのを最小案とし、両時計を明記する。

## 4. 5方策の公平な対照

|方策|制御・実行|必要な対照解釈|
|---|---|---|
|CONTINUE_MD|完全checkpointから同じlaneを継続。AI更新/推論/LOFなし|reseedしないので選点方策との差は行動束全体。更新だけの効果ではない|
|PERIODIC_UPDATE|k completed chunksごとの更新、k候補1/2/4は校正だけで調整|無調整k=1だけを弱い基線にしない。全基線にも同じdeadline保護|
|STALE_IMMEDIATE|固定M0で推論/LOFし候補を選ぶ|CONTINUEと異なる。推論/LOF/reseedを全額課金|
|ZW_ONLY|強Z/WからU/Sを判断|物理Wも保持し、費用則と有限候補の調整を公平に行う|
|ZW_PLUS_X|ZWにX1だけを追加、同じU/Sを判断|X計算/追加I/O/判断時間を含む実利益を測る|

同じ入力が公開済みでも、別方策が将来得たMDやmodelを共有しない。分岐後の候補内容が違うことは自然な方策効果であり、固定するのは生成・窓・件数規則。旧モデルで一度しか判断しない等、行動が等しい場合は同一基線として注記する。native-guided greedyは情報が異なるため、必要なら別のoracle的参考であり直接対等な主基線にしない。

## 5. 最小の段階的行列案

本表は**予算を審査する候補**で、全量を一括承認する指示ではない。H・recipe・根数の資格が未了なので実行seedやcommit凍結は次の承認時に行う。

|段階|最小案|目的・限界|
|---|---|---|
|既存開発|r01–r08、L2はr01/r02|既知結果。閾値や配方選定の開発材料で、未知確認には使わない|
|C費用/雑音校正|新4根、各S4一状態。Uは2更新seed×3MDseed、Sは共有3MDseed：**9枝/根、36 rollout**|固定親条件の学習/MD変動と費用を測る。F0重複なし。親初期化の分散は分離できない|
|C未知根診断|新8根を仮下限、各U/S×対応2MD stream=32 rollout案|一更新streamでは更新分散の一般化に限界。校正で不足なら件数改定を**開封前に**再承認。8根を確認的power保証にしない|
|B2未知方策|Cと別の新8根を仮下限、5方策×対応2stream=80 rollout案|全方策を同じHで測る。根内2streamは独立根ではない。Cを見て改定した方策にはC根を再利用しない|

旧案の4校正根×U/S各1回より校正反復を増やす理由は、N1/L2で明確になった学習・MD雑音の識別である。全量root追加の前にこの36本で打切り判断が可能となる。M0は各根の旧履歴から同一配方で構築し、U/Sはその同じ親model/optimizerから開始。初期化seedは固定する最小案なら、結論をその親生成規則に条件付ける。初期化に一般化する主張には別の交差対照が必要で、ここでは増やさない。

原論点のS4/S8因果分離をこの行列で解決したとは言わない。候補E、密度fit D、M0、訓練窓の各対照は別の機構研究であり、NMR参照変更では同定できない。[未識別表](budget-and-gates.md)。

## 6. 分割、割付と科学判断

校正4根と未知8根を共有しない。既存8根は全て開発済み。C未知結果を見て方策を改定した後は、同根のB2を未知確認と呼ばない。資源削減のためC/B2で未知根を共用する案を採るなら、**両方の仕様を最初の開封前に固定し、一回の共同開封**とする別承認が必要である。本書の推奨は段階判断を可能にする別root集合。

同rootのU/S/方策はGPUで逐次実行し、順序はblock内で結果非依存に無作為化する。学習/MD seedを別streamとし、(root, action/policy, learning block, MD block, chunk)の対応表を先に登録する。同じseedでも異なる起点では同じ軌跡ではない。shared Sを独立複製しない。未知結果を見た任意延長・停止・最良seedへの交換を禁止する。

最小実用差、CI精度、共通支持、費用割合、更新後に完了可能なchunk数を[予算・判定](budget-and-gates.md)で別に扱う。Cを支持しない場合も「データ不足」「Xが重複」「recipe依存」「効果が小さい」を区別する。B2で更新不要、X費用が利益を消す、干渉が小さい結果も残す。どの結果でも本作業の文書完成をC/B2の実行許可にしない。
