# 時間尺度・精度・費用と停止門

2026-10-30。以下の将来数値は**PROPOSED**。既報の実時間と算術上の費用シナリオを区別する。科学的効果を計算し直した資料ではない。

## 1. 600秒と4 nsの判断

既報B1下流4 nsは平均209.5531秒、更新子process平均4.2464秒、推論平均4.2532秒。[原費用](../P1-B1-Expansion/cost-and-runtime.md)。この値なら600秒のMD-only上限を単純換算して約11.5 nsと見積もれるが、起動・prep・失敗・公開、環境差を無視した外挿である。N1のCPU評価330秒はMDやGPUの費用ではない。

**判断**：600秒は小規模な資源/信号資格の候補にはなるが、確認的観測時間とは認めない。4 nsはnative値の変化を示す一方、最小値の瞬間性、Q/平均RMSDの不一致、根/seed変動を持つ。短い枝を増やせば長い障壁越えを観測できる、とは言えない。

|校正で見る条件（今は未実施）|選ぶべき対応|
|---|---|
|更新→推論→LOF→MD完了→公開がHにほぼ収まらない|科学信号の有無より先に公開粒度/資源計量を見直す。H延長は別承認|
|新しいbestが観測終端近くに偏り、4 nsで緩和が終わった根拠がない|固定全条件群の連続延長を検討。低RMSD枝だけ延長しない|
|同条件の短いMDseed間で効果の符号が大きく違う|校正でMD反復を保持し、ラベル不確実性を測る|
|根間の差が大きいが各根内の推定は比較的安定|追加rootを優先。frame/checkpointを増やして根nを代替しない|
|training seedで候補/ラベルが大きく変わる|学習配方と選点安定性の資格を先に審査|
|全条件でH内進捗が小さい・費用効果も小さい|無効果証明とはせず、精度/目的/時間尺度を再審査。閾値を緩めて成功にしない|

新たな長さ診断が必要なら、同じ事前指定の開発根/全条件群を4→8 nsへ**完全checkpointで継続**し、4/8 nsのnested結果を保存する小さい案を別途登録する。旧B1の特定成功枝だけを選ばない。これはNMR CPU資格にも資源だけのベンチマークにも含めず、新MDの別承認とする。800万frame等の総数より、実行単位と物理時間を先に固定する。

## 2. 最小実用差と最小検出可能差

δ_R [Å]を**最小実用差（SESOI）**、δ_pred [Å]をCの未知根MAE改善の最小実用差と呼ぶ案。いずれも**未採択**。RMSDの0.4 Åという既報段階差、最良3.614 Å、区間が0を跨ぐかを基に都合よくδを決めない。指導教員と、構造的解釈、NMR参照感度、数値精度、同seed条件の変動、計算予算に対する有用性を踏まえ、未知結果の開封前に採択する。NMR内部RMSD幅自体も自動的な生物学的δではない。

未知rootごとのB2対応差のSDをσ_Dとすれば、平均差の探索的標準誤差は概ねσ_D/√n。独立正規近似で両側α=.05、power .8を仮定した計画式

\[n\approx\{(z_{.975}+z_{.8})\sigma_D/\delta_R\}^2\]

は**粗い費用検討用**であり、小n、非正規min、階層、推定されたσの不確実性を無視する。n=8の確認的保証に使わない。B1の等MD量のSDやS8−S4のSDはB2の同実時間差のσ_Dではない。Cの予測誤差差のσも別である。既報bootstrapを再利用して未知方策のpowerと呼ばない。

最終nは校正のみから、不確実なσの保守的範囲を用いて、CI半幅≤δ_R/2等の**事前の精度目標候補**と実費用を同時に審査する。δが未定、校正が4根だけ、または必要nが設備予算に合わなければ、探索的研究として明示するか範囲を再設計する。未知根を逐次開封してp値が良くなるまで増やさない。

## 3. 4校正根と8未知根は何ができるか

4根は工程・費用・粗い雑音の診断には有用だが、高次元ZWモデル、ハイパーパラメータ調整、共通支持、独立検証の全てを保証しない。8未知根は既知8根より独立検証の意味を持つが、一般的な微小効果や多状態のCを確証する十分nとは未確認である。全て同じunfolded準備と物理系に条件付ける。別初期準備・別蛋白質への一般化はしない。

固定M0の下の2更新seed×3MDseedは行/列変動の診断を与えるが、1セル1MDでは純粋な交互作用と誤差分散は分離できない。共有STALEをtごとに複製せず、root bootstrap時は全state/seed/policyを一緒に持ち運ぶ。下位乱数の再標本化をする場合は交差構造を保つ独立の事前統計契約が必要で、単純な全枝bootstrapは禁止する。
