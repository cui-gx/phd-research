# 集計単位と解釈

本分析は既存B1へのPOST_HOC_EXPLORATORYである。34個のNMR参照は同一分子の参照感度で、34個の独立実験ではない。35番目の系列は34参照のframe別最小値と同じargminのQであり、新しい天然構造モデルではない。

## 固定集計

元2,048,000frame×34＝69,632,000 frame-reference組。各軌跡は12窓×2間隔、各系列は34固定＋min34の35。frame表を科学独立標本にしない。

期待出力は枝/履歴228,480窓行、状態40,320行、学習モデル67,200行、根対応80,640行、指標別根要約90,720行。モデル別dirに分割し、全34とmin34を同じ指標・窓・対比で保存する。

根r、状態s、臂aの指標平均をY_r,s,aとすると、D21=Y_F2−Y_F1、D10=Y_F1−Y_F0、D20=Y_F2−Y_F0。S4/S8に加え(D4+D8)/2とD8−D4を同根内で計算する。全8根を等重みにする。F1/F2は2学習seedの各3MDseed平均、F0は共有3MDseedのみ。学習seedとMDseedを混ぜた独立Nの膨張を行わない。

主窓のF2−F1最小RMSDは正ならF2が相対的に遠く、負なら近い。Qは大きい方がnative接触を多く満たす。RMSDとQの不一致を隠さない。min34のQはframe別argmin参照に条件付けられ、固定C1に対するQとは異なる。

8根bootstrapの95%探索区間は、固定seed17103001の10,000 root drawsを全参照/窓へ共有して算出する。複数参照/尺度/窓から有利なものを選ぶ確認的検定ではない。34参照間の点推定範囲・符号数と、根間の符号数・探索区間を区別する。

## 対応と測定交絡

主参照model1でS4正/S8負が他の固定NMRモデルでも残れば、参照model1の選択だけに依存した符号ではないという限定的根拠となる。候補pool、M0、学習window、状態履歴の交絡や、物理/学習資格の問題は除去できない。XがZ/Wを超える独立情報を持つこと、固定wall-clockのB2純利益、folding成功を示すものではない。

min34≤model1の絶対値低下は定義の性質。これをF2の戦略利益と呼ばない。参照感度が小さくても科学精度そのものが保証されるわけではなく、1FME ensembleの外側の参照・別物理体系・別タンパク質への外挿は行わない。

旧幾何distance_mean_Aとabsolute native endpointsのSpearmanは記述的関連。branchは同根/同モデル内で相関し、p値や独立240標本の推論は行わない。0.5psの既存幾何を使用し、新しい2ps幾何やC特徴量を計算しない。
