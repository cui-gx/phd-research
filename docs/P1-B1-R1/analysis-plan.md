## 3. 参照集合：固定する四つの評価法

以下の全ては再評価前の**提案**。採否は研究者審査で固定し、結果に応じてA2/A4を選び直さない。根をまたぐ参照の混合は行わない。

|ID|S4の参照|S8の参照|目的・情報の境界|
|---|---|---|---|
|ORIGINAL_HISTORY|H4|H8|元評価の読戻し。表示は「当時の履歴参照」とする|
|COMMON_A4|H4|同一H4|主再検証。各根のS4決定時までの共通履歴に対する変化|
|COMMON_A2|H2|同一H2|補助。M0_4構築時までの早期参照に対する感度|
|MATCHED_COUNT|H4|T_K(H8), K=\|H4\||補助。参照点数を一致させても時間域/構造分布は一致しない|

H2はrのh1（0–2 ns）の合格点で100 ps以後、S4の保存配列/元区間IDから取る。原時刻浮動小数の丸めで所属を作り直さない。H4とS8内のH4部分は座標・特徴・IDが一致することを要件とする。8根全体に一つの共通ライブラリを作る意味ではない。根固有の出発履歴に条件付けた比較であり、絶対的構象空間の被覆率ではない。

T_Kはglobal ID順のn点から位置floor[j(n−1)/(K−1)]、j=0,…,K−1を選ぶ決定的間引きとする。K>n、K<2、ID重複は停止する。応答・LOF・構造距離・Xを見て点を選ばない。これは「点数だけの純因果効果」を同定せず、時間域を保つ間引きへの感度である。重複座標を削除して密度を都合よく変更しない。

**時間合法性**：H4はS4/S8両決定の前、H2も両決定の前である。H8をS4に使うことは、たとえ実際のS4下流dispatchまでにH8が生成済みでも、S4の凍結情報集合を超える。今回の主・補助評価に「S4をH8で測る」対照を入れない。下流B、全群の和集合、応答を見て選んだ状態中心・閾値は参照構築に使用しない。

**事後評価とオンラインの区別**：COMMON_A4で測り直すのは実行済み枝のラベルである。S8で既知になった4–8 nsの領域も、H4から遠ければ高い値を取る。「S8時点で未発見だった領域」ではなく「共通の早期履歴からの変化」を測る。オンライン意思決定で使用可能な参照であっても、その指標を当時選んでいたこと、未来Yが決定時に分かっていたこと、方策改善が実現したことを意味しない。元の当時参照による成果も並記する。

## 4. 参照変更の数値的寄与

H4⊆H8なら全xでm_H8(x)≤m_H4(x)。平均・中央値・p90も同じフレーム集合なら非増加となる。しかし**群差の符号は単調でない**。F1/F2の双方の値が下がっても、下がり幅が異なればΔ21は増加し得る。

\[
\Gamma^N_r=D_{r,8}(H8)-D_{r,4}(H4),\quad
\Gamma^{C4}_r=D_{r,8}(H4)-D_{r,4}(H4),
\]
\[
E^{ref}_r=\Gamma^N_r-\Gamma^{C4}_r=D_{r,8}(H8)-D_{r,8}(H4).
\]

この恒等式を全指標・全比較について検査する。平均距離については、各群の参照拡大による低下L_a=Y_a(H4)−Y_a(H8)≥0からE^{ref}=L_1−L_2とも書ける。median/p90は枝ごとの統計量差として計算し、フレーム差のmedian/p90と取り違えない。

E^{ref}は**同一軌道の測定関数を変更した有限データ上の差**であり、候補選択やモデルの因果的な媒介効果ではない。Γが0付近なら比E/Γは不安定なので、「段階差の何%を説明」といった比率を主結果にしない。Å等の絶対差を根ごとに示す。離散greedy領域数には上記の点ごとの単調性を要求しない。参照変更で代表の採用順も変わるためである。

## 7. 統計単位と不確実性

まず各状態の全2×3セル、各群MD変動、学習行平均差、加法残差RMSを保持する。その後同根S8−S4を計算し、8根の平均・中央値・範囲・SD・全根点を示す。根内の二状態、参照法、指標、共有F0をまとめたcluster bootstrap10,000回、元seed1604000001を再使用する提案とする。これは解析用乱数であり、実験seedの変更ではない。同じ再標本化インデックスを全参照法/尺度/比較で共有する。

根を再標本化する主区間では下位seedを追加再標本化しない。有限2×3seedの雑音を含んだ根差に条件付けた探索区間で、精密な純分散成分や将来seed母集団の精度を保証しない。各段階の実seedは異なるのでS4/S8のセル差を「同一seed対応」と称しない。フレーム、100 ps窓、選択80個、再抽出候補を独立根数へ加えない。

元結果を見た後の多指標感度分析なので、有意差認定・後付けpower・等価性認定はしない。全区間は探索的で同時被覆を保証しない。根別leave-one-root-outの8平均を影響診断として併記する提案とし、外れ根の除外基準やCの交差検証性能に転用しない。符号・区間の変化を全指標で記載し、最も有利な参照法を選ばない。
