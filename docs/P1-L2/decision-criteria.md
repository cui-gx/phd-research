# PASS・FAIL・INCONCLUSIVEの判定と主張の限界

2026-10-29、PROPOSED。本輪の文書完成は、下記科学判定のPASSや実行承認ではない。事前に実用的な同等幅を設定できる独立校正がないため、「改善が止まった」「十分収束した」という判定は本L2の自動出力にしない。

## 1. 判定を分離する

|判定対象|PASS / 限定支持|FAIL / 支持なし|INCONCLUSIVE|
|---|---|---|---|
|技術完全性|入力/親/ID/SHA・step/提示/RNG監査、固定行列・全必須表が完備、旧証拠不変|SHA不一致、親の誤復元、条件逸脱、非有限、原資料変更|中断・未実施・一部欠測。成功セルだけでPASSにしない|
|頻度を超える再構成|指定セルでA_train>0|A_train≤0ならそのセルの優位は支持なし|OLD/RECENT、seed、mask間の方向が混在。LOOとの勝敗で置換しない|
|個別入力依存の限定支持|指定セルでA_mean>0かつ5つ全てのA_perm>0。正の大きさも必ず報告|平均コード/全入替えに対して優位がなく、限定検査で入力対応の有用性を示せない|対照ごとに符号不一致、差が数値再現性の範囲、強い時間相関で検査が鈍い|
|学習による物理幾何の限定支持|RAW K10が同init未学習step0より高い。値・Spearman・接触/時刻基線を併記|改善なし、または未定義/退化。再構成優位で代用しない|集合/seed/step間の不一致、局所と大域の不一致|
|200歩より先の有用な変化|同chain1600対200でBCE低下とK10上昇を共に観測したセルを列挙。全中間増分を公開|訓練lossのみ低下、検証/幾何が改善しない場合はその問いを支持しない|RECENTだけ改善、OLD悪化、途中だけ改善、seed不一致|
|初期化に対する安定性|全対応値と3対の一致度を記述する。観測範囲に限定|完全一致がないことだけで学習失敗にしない|3seed・1optimization streamでは汎用的安定性の合否幅を認定できない|
|LOF感度|Top1/全順位/TopK/物理起点差を全比較で定量記述できる|技術失敗で選択不能ならFAIL|変化の良否・科学的価値は常に未評価|
|学習十分性・探索価値|本L2だけで全面PASSを出さない|陰性結果だけで全CVAEが無価値とも断じない|収束・一般化・科学探索・C/B2はUNVERIFIED / NOT TESTED|

上の「>0」は有限データ上の方向の符号であり、有意差・実用差の閾値ではない。再forwardの決定性誤差と比較して符号が信頼できない場合はINCONCLUSIVEとし、差を丸めて合格にしない。数値不一致を許す新toleranceが必要なら実装点検段階で理由と測定を提示し、結果を見て都合よく緩めない。

## 2. 全体見出しの事前規則

最終1600時点で、各臂につき4状態×3init×2集合×NONLOCAL/LONGの48セルを一つも省略しない。再構成・入力依存・未学習より高いRAW幾何が全対象セルで揃う場合だけ、その臂について「検査した有限集合で非自明表現の一貫した限定支持」と記す。ALL784だけを満たしても該当しない。幾何はmaskに依存しない同じ値であり、48独立幾何反復に数えない。

一部だけ揃う場合は**部分的支持 / INCONCLUSIVE**として、成功数の分母、失敗セル、OLD/RECENT、S4/S8、全seedを並べる。これは厳格な見出しの統一規則であり、全セル一致が自然科学上の普遍的合格基準という意味ではない。どの場合も学習十分性の全面PASSは保留する。

「200歩不足」は、より長い学習が同じデータで役に立つという条件付き証拠の表現に留める。800→1600でも改善が続くなら1600を収束点と認定しない。改善が見えなくても、最適化停滞、モデル容量、入力表現、損失目的、診断の感度不足を排除できず、「200で十分」とは逆推論しない。

## 3. 判定後に許される提案

|観測の型|次に研究者が検討する選択肢|自動でしてはいけないこと|
|---|---|---|
|歩数を増すと両集合で改善、幾何も改善|新レシピ候補を独立根で検証する別計画|最良stepを旧B1へ差し替え、B1成果を再解釈|
|BCEだけ改善、幾何は停滞|目的関数/低次元表現と必要機能の整合を再審査|latent_dim、KL重み、学習率を無断探索|
|初期化によって方向が異なる|更新seed交差追加の情報価値と費用を審査|良い初期化だけ採用、3seedで一般的有意性を主張|
|LOFだけ不安定|密度尺度と近接score・幾何の問題を別審査|Top1を実行済み下流MDに見立てる|
|全て弱い/悪化/有限loss尖峰|陰性として保存し、限定利用または別案を検討|1600を超える自動延長、異常rootの削除|

Pの物理資格、Oの独立参照、CのX追加情報、B2の固定wall-clock利益は別ゲート。L2のどの結果もその自動承認につながらない。
