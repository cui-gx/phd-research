# 成果指標の比較と主指標候補

2026-10-28。**全てPROPOSED。既存B1/R1の指標を変更せず、新しい数値も計算しない。** 旧指標は全条件を公開し続ける。

## 1. 先に固定すべき科学的目的

目標は「FSD-EYの定めた物理プロトコルと初期集団において、限られた計算時間で、既に観測した形だけを繰り返すことなく、説明可能な構造範囲を追加して観測すること」とする案である。天然構造に近づくこと、平衡人口・折り畳み速度の推定、新準安定状態の認定は含めない。物理資格Pが未解決なら、結果は「当該モデル内の構造幾何ベンチマーク」と限定する。

適応サンプリング文献でも、探索と遅い過程の評価は同じ目標ではない。Hruškaらの比較はMSM由来の合成軌道であるため、そこから本実MDの主指標の妥当性まで借用しない。[原著§II-C、目的別比較](https://www.kavrakilab.org/publications/hruska2018quantitative-comparison-of-adaptive-sampling.pdf)

## 3. 主指標案：独立参照構造への被覆距離の改善

### 3.1 固定する対象と数式

Pは28個のCαのうちi<jかつj−i≥3の325組。非周期座標を用い、内部距離をÅで測る。旧幾何量と同じ表現を利用するが、集約方向を明確に変える。

$$
d(x,y)=\sqrt{\frac{1}{325}\sum_{(i,j)\in P}
(\|x_i-x_j\|-\|y_i-y_j\|)^2}\quad[\mathrm{\AA}].
$$

独立に用意して凍結する参照集合をR={r_j}、固定重みw_j≥0、Σw_j=1とする。非空観測集合Sに対する未被覆距離を

$$L_R(S)=\sum_j w_j\min_{x\in S}d(r_j,x)\quad[\mathrm{\AA}]$$

と定義する。決定時点で適格かつ利用可能な履歴H_s、行動a後に締切Tまでに公開・品質判定が済んだ新しいMDフレーム集合D_{a,s}(T)に対し、

$$
G_R(a,s,T)=L_R(H_s)-L_R\{H_s\cup D_{a,s}(T)\}\quad[\mathrm{\AA}]
$$

を主成果候補とする。大きいほど、固定参照構造のうちまだ近くに観測を持たなかった形へ近づいた。これは**構造範囲の代表に対する幾何的被覆改善**であって、真の構象空間の体積割合、発見状態数、熱力学量ではない。本プロジェクトの操作的提案であり、分子動力学分野の公認標準指標とは主張しない。

### 3.2 この方向に集約する理由

従来の平均m_H(D)は「新しい観測から古い集合への距離」で、同じ遠い形を多数回保存しても高値を維持し得る。G_Rは「固定された参照の各形から蓄積観測への距離」であり、Dの同一フレームを追加しても変化せず、観測追加で減らない。移動・回転に不変で、閾値εで高低を切らない。H_sを全臂共通にするため、同じ状態でのF2−F1では初期項が相殺される。

ただし内部距離は鏡映に不変で、側鎖・水素・局所二面角を全て区別しない。手性・結合・角度の安全/補助評価は必要である。単一の異常フレームが参照に近づくこともあり得るため、数値健全性とプロトコル資格を別に要求する。「距離が小さくなれば物理的に良い」とは定義しない。

### 3.3 参照庫を結果に合わせて作らない

提案する分離は三段階である。

1. **既存B1/R1の8根**：仕様開発・反例検討だけ。既知のF2成果を持つため、未知テスト根に再分類しない。
2. **参照/校正根**：別の準備・乱数系列を、採択済みの同じ物理プロトコルと行動臂に依存しない生成規則で取得する案。参照構築群と参照妥当性確認群を根単位で分け、校正で方式を修正したら新versionにする。
3. **効果検証根**：R、重み、品質判定、保存間隔、主窓、停止条件をcommitし、検証根のF1/F2成果を見ない状態で凍結する。Rは評価器側だけが保持し、候補選択・X・学習へ渡さない。

初期案の重みは、参照構築根を等重み、その根内の固定間隔フレームを等重みとする（w_{kj}=1/(K n_k)）。これは「生成規則が与えた根ごとの有限構造集合への近さ」であり、各物理状態の等重みでもBoltzmann重みでもない。根やフレームを結果依存で削除しない。参照の重複や特定初期状態への偏りは記録し、対照方策の優劣を見て重みを変更しない。

候補となる保存間隔は2ps、補助感度は4/8ps、枝の初期除外は既存100psを出発案とする。ただし100psを平衡時間と認定しない。適切さはP資格と校正群で判断し、最終選択と理由を**効果検証前**に承認する。G_Rは閾値をなくしても、参照・品質・時間設定の事前固定を不要にしない。

必要な参照規模・長さは現時点で未決定である。例として4構築根＋4診断根を同じ8nsで用意する案は費用表に記すが、8nsや8根で十分だとはしない。校正で安定しなければ費用枠を自動拡大せず停止する。NMR34構造や他の力場/温度の長軌道を、説明なしにRへ混ぜない。

### 3.4 凍結前の失敗条件

|診断（将来、別承認）|不合格または制限する状況|対処|
|---|---|---|
|同じDの複製、順序、剛体移動の静的性質|理論上の不変性に反する実装値|実装不合格。成果比較しない|
|独立校正根に対する最近傍距離分布・根別寄与|参照が一準備/一根の狭い形だけを表し、目的範囲から外れる|参照範囲の主張を狭めるか、新版を別承認|
|参照構築根のleave-one-root-outと固定間隔感度|尺度が強く不安定、わずかな重みで結論が入れ替わる|確認的主指標READYにしない。全感度を残す|
|Dの1/2/4ns増加に対する余地|初期Hだけでほぼ飽和、または測定精度より変化が小さい|検出力不足。F2有利な窓へ移さない|
|Rg/Q、二面角、手性等との対応|改善が異常構造・単なる伸長・品質除外で生じる|科学成果の解釈を停止|
|範囲外の新形|Rにない形を妥当に観測しても評価しない|out-of-reference診断を併記し、有限ベンチマークと明示|

ここで「ほぼ」「強く」の数値許容幅は、校正で測定分解能・用途を確認し研究者が承認する未確定項目である。未設定のまま確認的試験を始める実行カードではない。最低限の数学的性質と有限Rへの推定対象は定義済みだが、科学的十分性はUNVERIFIEDである。

### 3.5 締切・失敗・選点の扱い

選ばれた座標は既にH_sにあるので、選点そのものを追加発見として数えない。最小化だけで動いた座標もMD成果にしない。Dには積分後、事前固定の初期区間除外を終えたMDフレームだけを入れる。reseed緩和・I/O・品質判定を含む時間は消費として残す。

Tは秒の利用可能時刻で、MDのnsと区別する。Tまでに適格MDがなければD=∅でG_R=0。破損・品質失敗は「良いフレームだけの勝利」にしないため、行動ごとの失敗率・未公開量・消費時間を残す。計算失敗を研究者が定めるintent-to-run方針に従って扱い、成功枝だけの分析は補助にする。安全性の根本的失敗はランキング自体を保留する。

## 4. 必須の補助指標と安全指標

主指標は一つを事前指定するが、科学を一つの数値に還元しない。

- **探索の別の面**：当時履歴へのmean/median/p90距離、Rgと非native Q8、最近傍との二面角差、旧六ε/τ条件、全事前窓。増減方向を一律に「改善」としない。
- **参照依存**：凍結Rの根別寄与、範囲外距離、保存間隔・参照診断版。これをF2有利な主指標の再選択に使わない。
- **物理安全**：数値有限性、制約残差、結合・近接・手性、温度/勢能の時系列、準備・reseed後の局所緩和、除外率。未承認の新閾値を旧証拠へ適用しない。
- **システム**：実MD量、期限内公開フレーム、MD/準備/訓練/推論/選択/品質判定時間、失敗・待機・メモリ。GPU利用率は成果の代用にしない。

主効果は同根同状態・対応seedのG_R差 [Å]。G_Rから秒を直接引かない。固定MD量効果と固定wall-clock効果は[最小設計](minimal-design.md)で別定義する。複数副指標の中で有意なものだけを結論に採らない。
