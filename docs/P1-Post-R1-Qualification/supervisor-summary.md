# 指導教員向け概要：次の実験を始める前に何を確かめるか

2026年10月28日。文書審査のみ。新たな分子動力学計算・学習・推論は実施していません。

## 研究の目的

本研究は、FSD-EYという28残基の小さな蛋白質を計算対象とし、OpenMMによる分子動力学とCVAEによる構造選択を一つのGPU上で実行するものです。蛋白質の折り畳み機構や新しいAIモデルの開発が主題ではありません。限られた計算時間をMDの継続とモデル更新にどう配分すれば、より有用な構造探索につながるかを調べます。

現在の中心的な問いは、更新前の科学データの状態が、計算費用・データ量・学習状態だけでは分からない更新価値の情報を与えるか、というものです。この問いは、単にGPUを忙しくすることや、モデルの損失を下げることとは異なります。

## これまでに分かったこと

8本の独立乱数による履歴から、4nsと8nsの計16状態を作り、240本の下流MDを比較しました。学習量を揃えた旧データ再学習F1と、新データを半分含めた再学習F2を比較しています。これは同じMD量での比較であり、同じ実時間予算での利益はまだ測っていません。[B1報告](../P1-B1-Expansion/review-dossier.md)

続くCPU再検証では、元の結果を再現し、評価の参照構造を揃えて比較しました。共通4ns履歴を参照した幾何距離では、F2−F1の8ns状態と4ns状態の差は+0.680Åで、探索的95%区間は[0.285,1.090]Åでした。一方、共通2ns履歴では−0.101Å、区間[−0.553,0.302]Åでした。離散的な領域数でも一貫した優位は確認されていません。[R1主表](../P1-B1-R1/main-root-summary.csv)

したがって、「更新の効果が条件によって変わる可能性」は残りますが、「科学的探索が一般に改善した」「科学状態Xが独立に予測できる」とはまだ言えません。距離の参照を変えると、測っている構造の違いも変わるためです。

## 今回明らかにした資格上の課題

**物理系**：入力ファイルと原子・計算条件は追跡できますが、上流unfolded構造の作製履歴、プロトン化条件、局所緩和の十分性が未確認です。GBn2/NoCutoffの計算成功や結合の健全性だけで、物理的な妥当性全体を認定しません。なお、限定した非平衡の局所探索を研究するために、全ての大域平衡を達成することまで要求する計画ではありません。[物理審査](qualification-review.md)

**学習系**：同じ重み・optimizer・学習歩数を用いた対照は確認済みですが、M0の200歩、更新の追加200歩で十分な構造表現が得られたかは未確認です。またソース上、訓練と検証のlossはbatchの大きさによって尺度が変わり、そのまま比較できません。損失低下や候補変更だけを科学的利益とは扱いません。[学習審査](qualification-review.md)

## 次の小さな計画案

まず追加MDをせず、保存済みの準備記録、80モデルの学習ログ、既存MDログを整理する案です。その結果を基に、必要な物理確認と学習量確認を別々に最小化します。

主成果には、行動とは独立に固定した参照構造集合に対し、未被覆の幾何距離をどれだけ減らしたかを測る案を提示しました。参照は天然構造一点ではなく、事前に定めた構造範囲です。反復して同じ形を見るだけでは加点しません。ただし、その参照範囲の妥当性は別に確認する必要があり、今回採用を確定していません。[成果定義案](outcome-definition.md)

候補として選べる構造、LOFの密度推定に使う構造、初期モデル、更新学習窓を切り分ける対照も設計しました。最後に、条件の揃う新しい履歴根でXの追加予測情報を調べます。実時間の機会費用を含む比較は、さらに別の承認段階です。[最小設計](minimal-design.md)
