## 3. 新しい参照評価の計算量

参照K点、観測F点、325内部距離で素朴計算はO(325KF)。全距離行列を常駐させずchunkごとに参照点の最小距離だけ更新する案で、補助メモリはchunk設計に依存する。主評価器をオンライン候補判断へ隠れて追加しない。評価費用を全臂共通の事後評価とする場合と、期限内の品質確定に必要な処理を区別して費用契約へ書く。

OのKやframe strideは校正で凍結する未確定項目。RAM・時間の事前点検をせず大規模全対距離を開始しない。R1の約7000s CPU実績は別評価器のため、そのまま新評価の所要時間に用いない。[R1費用](../P1-B1-R1/costs.json)

## 4. 検出力と根数

新しい成果G_Rには既存m_Aの分散をそのまま転用できない。必要根数を「8根で有意だったから8」と決めない。校正で推定した根レベルのばらつきsと、研究者が設定した実用差δを用い、たとえば対応平均の正規近似N≈(z_{1−α/2}+z_{1−β})²s²/δ²を初期目安にできる。ただし予測誤差差D、裾・外れ値、小標本、モデル選択、seed雑音では前提が異なるため、その用途の根単位設計を別に登録する。

これは式の提示であり、本輪でpower計算・bootstrap・シミュレーションをした意味ではない。検出力が足りなければINCONCLUSIVEを受け入れる。結果を見ながら根数を増やして有意になった時点で止める設計にしない。
