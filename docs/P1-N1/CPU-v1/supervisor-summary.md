# 指導教員向け概要

既存FSD-EYのB1軌跡を、1FME model1/28Cα proper RMSDと42 native接触の回復率Qで事後評価した。全32履歴・240下流、2,048,000点をCPUのみで処理し、入力・品質・時刻・原子対応が一致した。

主窓4ns/最初100ps除外におけるF2−F1の枝別最小RMSD平均差は、S4で+0.397Å、S8で−0.399Å、二状態平均ではほぼ0だった。更新の影響は段階で異なるように見えるが、候補pool・初期モデル・履歴の違いがあり、科学状態Xの独立価値とは言えない。Qも総合的な更新優位を支持しない。全体最良3.614Åは折り畳み成功の認定ではない。

4ns内でも天然構造接近の測定信号はある。ただし新MDも固定実時間方策比較も行っていないため、C/B2の予算・学習recipe・物理条件の資格を別途審査したい。34NMR依存、準備/pH/平衡、CVAE表現資格は未解決のまま保持した。新計算へ自動進行せず、独立審査をお願いする。
