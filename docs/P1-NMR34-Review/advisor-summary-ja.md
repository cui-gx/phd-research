# 指導教員向け概要：天然参照に対する感度の確認

2026-10-31。既存のFSD-EY分子動力学結果について、主参照の1FME model1を含む34個のNMR構造を使った感度分析を審査しました。新しいMDやAI学習は行っていません。

本実験では、旧モデルを固定するF0、旧データだけで追加学習するF1、新旧データを混ぜて同じ歩数だけ追加学習するF2を比較しています。下流は各4 nsのMDです。8本の独立乱数履歴の4 ns時点（S4）と8 ns時点（S8）を比較しますが、同じ履歴の両時点は独立標本には数えません。

**確認できた点**は、F2−F1の枝別最小Cα RMSDの平均方向が、34固定参照のすべてでS4は悪化、S8は改善となったことです。主窓の差はS4が+0.353～+0.457 Å、S8が−0.441～−0.354 Åでした。したがって、model1だけを選んだためにこの平均方向が生じたとは考えにくい結果です。ただし、34参照は同じNMR構造族であり、34回の独立実験ではありません。

**確認できていない点**は、更新の全体的な利益です。model1の二時点平均差は−0.001 Å、8履歴根に基づく探索区間は[−0.205,+0.217] Åでした。平均native-contact Qでも一貫した優位はなく、F2−F0の平均Qは−0.0215と不利でした。最良RMSDだけから「AI更新は有効」と結論しません。

またS4/S8では、利用できる候補数、モデル、訓練データ窓、探索履歴が同時に変化しています。今回の結果は、これらを分離した科学フィードバックの効果ではありません。更新・推論・候補選択に費やす時間もあるため、等しいMD量での比較を、同じ実時間予算での調度効果と読み替えることもできません。

技術面では全272軌跡と保存表の整合性を確認しました。原CSVに欠けていた窓完全性と有効点数を附表で補いました。2 nsの歴史軌跡について要求された4 ns窓は未完了として扱い、下流の4 ns比較には混ぜていません。

今後は、同じデータへの参照分析を繰り返すより、**固定した科学評価、実際の更新費用、deadlineまでに使える成果**を結び付ける準備へ進むことを提案します。現物理体系は限定的な非平衡探索ベンチマークとして説明し、pH・準備履歴・CVAEの安定性の未確認点を明示します。熱力学的平衡やfolding機構の再現を新たな研究目標にはしません。
