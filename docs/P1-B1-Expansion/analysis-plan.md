# B1 Expansion 事前実験計画 v1

2026-10-26。推奨Sol High。研究者の最新の添付指示を根拠に実行し、旧Pilot停止指示は今回の承認範囲についてのみ更新する。P1の科学対象・モデル・物理条件は変更しない。

## 問いと推定対象

Q1：更新で選点が変わり、その変化は学習seedでどの程度変わるか。Q2：同じ4 nsの下流幾何代理に差があり、MDseed変動と比べてどの程度か。Q3：根/4・8 ns状態の差と、決定前の科学フィードバックに今後検証すべき関係があるか。F2勝利、有意差、折り畳み、唯一の真の状態数を要求しない。

YごとにΔ21=Y2−Y1、Δ20=Y2−Y0、Δ10=Y1−Y0を計算する。Δ21は同学習量でデータ組成を変えた総効果であり、新規性だけの効果ではない。更新の実費用は測るが、B1のYから秒数を引かず、固定wall-clock純利益を主張しない。

## 対象と物理条件

FSD-EY/1FME、DeepDriveMD b18dacbaの固定unfolded入力SHA `8cb0382cb19e24c1159eb672b236bc1a6642fc8025e6c5cb8200c3c4c435d2b3`。504原子/28残基。Amber14-all/GBn2/NoCutoff、非周期、300 K、Langevin摩擦1 ps⁻¹、2 fs、HBonds許容10⁻⁵、CUDA mixed/DeterministicForces=true。0.5 ps出力。初回だけ最小化10 kJ/(mol nm)、maxIterations1000、300 K速度生成。履歴2 ns区間の継続は完全checkpoint、再最小化/再速度生成をしない。下流全240本は座標再最小化＋速度reseedを揃える。準備史/pH/十分な平衡はUNVERIFIEDを維持する。

8根は同じ準備構造に条件付けた別乱数履歴で、独立準備条件ではない。各根の4/8 nsは同一祖先。下流フレーム、240本、16状態を8根と同等の独立数にしない。

## データ・モデル・選択

[data-lineage-plan](data-lineage-plan.md)の固定相対窓で旧800・検証200・新400を選ぶ。旧800の偶数位置400をF2旧成分とする。容量不足/同一座標の補充は禁止。M0は全状態で未学習の同一初期化seed1600000001から旧800を200歩。これは継続的AI履歴の忠実再現ではなく、初期化と学習量を揃える制御モデルである。全M0の初期モデル/optimizer digestを照合する。

既存mdlearn CVAE938cb80、28×28二値8 Å接触、filters16×4/kernel3×4/stride1,1,1,2/dense128/dropout0.5/latent3、RMSprop lr0.001/weight_decay1e-5、元loss・clip10を維持。M0/F1/F2はbatch4×200歩=延べ800提示、F1/F2は同M0 weight/optimizerから同ブロック初期RNGと同位置permutationを使う。検証は診断専用、early stoppingなし。

P4/A0_4は100<t≤4000 ps、P8/A0_8は100<t≤8000 psの合格全履歴。全条件で同SHA。既存CVAE predict batch64、seed2026102671、LOF20/Minkowski p2/novelty=False/n_jobs2、negative score昇順、tieはglobal ID。Top1/10/100、全順位/embedding/scoreと原DCD対応を保存する。native参照なし。F0は状態ごとに同一条件で二度推論し一致を検査する。

## 階層分析と欠損

各状態でY1/Y2は2×3セル、Y0は共有3セル。Δ21は同T/Mの6対。Δ20/10もF0の同Mへ対応付けるが、共有IDを保持する。状態平均はT/M等重み、F0は3本の平均を一度だけ使う。根平均は4/8 nsを等重み。8根の全点・平均・中央値・範囲、状態差と根級percentile bootstrap（10,000回、seed1604000001、95%）を記述する。全状態/指標を一緒に根単位で再標本化し、相関を保持する。探索的区間で功效/有意性を認定しない。

固定モデルのMDseed標準偏差、TごとのMD平均差、Δ21の2×3セル、行列の行/列主効果と加法残差RMS、根間分散、同根8−4 nsを併記する。1セル1回なので加法残差は純粋な交互作用分散ではない。2 T/3 Mの分散は不安定で、精密分離や複雑混合モデルの収束を必須としない。

C診断は同時刻8根内のXの範囲・標準偏差、Z/Wとの散布図/相関、Δ21との記述的Spearmanを全X/全主代理で報告する。Xの時刻内変動があるかを確認するが、完全なZ/W条件付き識別・因果性・C予測性能は認定しない。正式価値予測器を学習しない。

欠損はNA+原因、分母と全予定IDを保つ。完全な対応がない差はMISSING_PAIR、0補完なし。根平均/bootstrapの完全根数を明示し、欠損根の削除で結論を美化しない。入力・SHA・科学条件違反は停止。幾何失格フレームは規則どおり除外して全数/理由を保存し、失格で有利な枝を選別しない。科学的な不利益は再実行理由でない。工程失敗だけ新attempt IDで同条件復元する。

## 実行と停止

全乱数と240枝順序はJSON/CSVで固定する。r01の履歴・状態・選択と予定行列の最初の1枝で工程連鎖を検査する（追加MDでない）。その後残りの履歴と状態/選択、全残枝を実行する。最初の効果の正負によって他根実行を選別しない。単一GPU単槽、逐次CPU分析、分枝/根の完了印、入力/出力SHA、実GPU診断を保存する。[資源規則](resource-and-recovery-plan.md)を守る。

全証拠・日語報告・図・原データの検証済みバックアップ・本人一時資源の清掃・GitHub回読後に停止する。B2/C正式予測/S3や240本を超える追加科学実験は別承認が必要。
