# 物理代理と決定前状態の固定契約 v1

全て探索用の操作定義で、唯一の蛋白状態数や生物学的価値の認定ではない。単位と原子対応はPilot/R2を継承する。非周期のÅ座標、28Cα、P3={j−i≥3},325対、P4={j−i≥4},300対。

## 下流Y

d(x,y)=sqrt(Σ_P3(Dij(x)−Dij(y))²/325) [Å]。同状態の合格履歴全点A0へのm(x)=min_h d(x,h)の平均/中央値/p90、全距離配列、100 ps窓を保存する。A0は枝の将来データを追加しない。

R2の増分領域：ε1.5/2/3 Å×τ0/5 ps、間隔2 ps、A0全点＋追加代表へ重複排除。初点を無料で種にしない。代表、確認frame/物理時刻、繰返しを保存する。5 psは2 ps離散観測で最短6 ps、順序/τ/尺度に依存する操作量である。

主表示は4 ns/除外100 ps、全連続量と6離散条件。感度は除外0/200/500 ps、prefix1/2/4 ns。等重みCα Rg [Å]、Q8=Σ_P4 I[Dij<8Å]/300、54主鎖角の周期差RMS[度]、Rg/Q8の時間相関も補助。結果に有利な一尺度へ絞らない。単位の違う値を合成しない。鏡像不識別・初期緩和・同一構造由来の相関を明記する。

## 決定前X

旧800 Oと新400 Nは固定訓練抽出ID。x1=|N|⁻¹Σ_x∈N I[min_o∈O d(x,o)>2Å+1e-10Å]、0–1。旧・新容量を全状態で揃える。x1_distance_mean_Aも補助として保存する。下流Yと同じ距離表現の機械的関連を開示する。

x2=JS(p_N,p_O) [bit]。固定Rg/Q8セル g(x)=(floor(Rg/0.5Å),floor(Q8/0.05))、原点0、範囲外クリップなし。共通和集合の経験ヒストグラム、log2、0log0=0、平滑化なし。0≤JS≤1。投影混叠は残る。

x3=[U_grid(H_t)−U_grid(H_b)]/2ns [セル/ns]。Hは共通履歴の100 ps以後の品質合格点を2 ps間隔で時系列抽出し、b=t−2ns、同じ固定gを使う。x4は最近(b,t]の2 ps適格点のうちH_bで訪問済みセルに入る比率。x3/x4はWと情報を共有し、独立の科学情報と仮定しない。空集合はnull+理由とし、擬似0にしない。閾値・セル幅は生物学的最適値でなく本探索の固定尺度である。

## Z/W

Z：根/状態の祖先ID（照合用で予測特徴ではない）、決定時刻4/8ns、完了MD量、候補数、旧/新/検証数、モデル累積200歩、モデルの物理データ年齢2ns、実際の公開後経過秒、固定配方/環境SHA。事前費用推定はPilot由来4.0秒/更新、3.5秒/推論、208秒/4ns MD、出典670fac9と費用証拠SHAを保存する。本状態の追加更新の実測費用を回填しない。残wall-clock horizonはB1では未設定なのでnull+not_applicable_equal_MD。

W：同じ2 ps H_tのU_grid、Rg/Q8の平均/標準偏差/範囲、最近区間のU_grid、過去セルへの繰返し率を保存する。有限履歴の記述で、全構象空間の被覆率ではない。X/Z/Wを一つのimmutable JSONへ保存し、inputs_available≤feature_start≤feature_end≤state_frozen<branch_dispatchを検査する。CPU費用と入力SHAを別記する。

## 品質・欠損

Pilot/R2の固定規則：有限座標/54角、拘束残差≤0.01Å、隣接Cα2.5–5Å、ペプチドC–N0.8–2Å、非隣接残基重原子距離≥0.8Å、準備構造に対する側鎖手性。全原子504/28残基/Cα順とSystem一致。温度/エネルギーを診断し、後から都合よく閾値追加しない。十分な平衡やpH資格ではない。

### 初回GPU前の実装明確化（2026-10-26）

新旧の所属は保存元2 ns区間/global frame IDでも制限する。境界bの旧側はID<b/0.5ps、新側はID≥b/0.5ps。時刻の微小な累積誤差で最後の旧フレームを新データへ混入させない。時刻原値は書き換えない。W/Xの過去・最近区間もこの排他的な元区間規則で分ける。物理窓、標本数、seed、全行列は変更せず、元指示の新旧分離を実装する明確化である。初回科学GPU計算前に再push/遠隔確認する。
