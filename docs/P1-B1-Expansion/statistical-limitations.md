# 統計単位と解釈の限界

頂点単位は同じ準備構造に条件付けた8履歴根。4/8 nsは同根で関連し、240分枝、モデルseed、保存フレームは同等の独立科学実験ではない。別準備、力場、蛋白質、CVAE学習設定の一般性は評価しない。

F0共有3本をT1/T2へ対応付けても独立数は3。F1/F2の2T×3Mは、固定モデル下のMD変動、Tの平均差、加法残差を記述できるが、1セル1本で純粋な交互作用分散を精密に同定できない。根間分散も測定雑音を含む。8根のbootstrapは探索的な区間で、事前の検出力認定ではない。

X/Z/Wは全て決定前に固定する。時刻内のX変動と効果の相関は、Z/W条件付き予測増分、Xの因果性、オンライン方策の価値ではない。Xと結果が同じ距離表現を共有し、最近増分がWと機械的に関連することを開示する。複数尺度/特徴から最良の関係だけを選ばない。

S8は候補数/A0/履歴量、旧訓練窓がS4と異なる。時刻差をXだけに帰属できない。短時間reseedの松弛、初期準備/pH、NoCutoff/GBn2、GPU/時段差、同初期化M0と小さな訓練量にも条件付けた結果である。更新実費用が小さい場合、それを実部署の性質として記録し、無意味な訓練追加で競争を作らない。

B1は等MD量であり固定wall-clockの純利益ではない。正式B2/C予測器/S3は未実行・未承認。科学的結論は全範囲と欠損を確認した後に研究者/計画側が審査する。
