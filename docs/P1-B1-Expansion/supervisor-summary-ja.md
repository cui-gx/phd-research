# 指導教員向け：B1拡張実験の目的と現在の段階

2026-10-26。**実行中であり、本輪の研究結論は未確定です。**

目的は蛋白質構造やCVAEの最適化ではありません。FSD-EY/OpenMMと既存CVAEを実験対象として、新しいMDデータでモデルを更新する判断が次の起点と下流計算の幾何探索代理を変えるか、またその差をランダムな変動から区別できるかを調べます。

8本の独立乱数による連続8 ns履歴から、各4/8 ns時点の16状態を作ります。各状態でF0凍結、F1旧データ追加学習、F2新旧混合学習を比較し、F1/F2の学習量を200歩/800サンプルに揃えます。2学習seed×3MDseedの交差設計、各4 nsで下流240本/960 ns、履歴64 nsです。F0は3本を共有し、複製して独立数を増やしません。

従来Pilotでは選点と下流形状に差がありましたが、F2−F1の符号は二乱数ブロックで一致しませんでした。今回はその原因が同状態内の学習/MD変動なのか、履歴・状態の違いにも関係するのかを探索します。全ての指標とX/Z/Wを結果前に固定し、不利な結果でも保存します。

頂点は8履歴根で、16状態や多数のフレームを独立根とは見なしません。同一準備構造、NoCutoff/GBn2、小さなCVAE配方に条件付けた探索です。距離/領域数は幾何代理であり科学発見価値ではなく、固定MD量のB1から固定wall-clock純利益は結論できません。正式C予測器やB2/オンライン方策/S3は実行しません。

現在は事前計画・完全seed行列・実装とサーバ工程試験を終え、最初の履歴と予定枝の工程核証を終え、残りの固定行列を実行しています。全範囲・原データbackup・監査後に結果を報告し、研究者の審査を待ちます。
