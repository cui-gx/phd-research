# 制御M0と対応更新：全状態の学習仕様

2026-10-27。16 M0＋64追加学習、80保存checkpointを完了しCPUで内容読戻し済み。全モデル記録は [models.json](../执行证据/2026-10-26-b1-expansion/models.json)、復元は [checkpoint-readback.json](../执行证据/2026-10-26-b1-expansion/checkpoint-readback.json)。これはモデルの科学的有用性の資格ではない。

## 固定配方と推定対象

mdlearn938cb80のSymmetricConv2dVAE、28×28二値8 Å接触、filters16×4/kernel3×4/stride1,1,1,2/dense128/dropout0.5/latent3、RMSprop lr0.001/weight_decay1e-5/clip10。入力標準化器を新たに学習しない。M0は同未学習初期化seed1600000001から旧800をbatch4×200歩。S8 M0も新しく作り、S4から継続学習しない。

F0=M0凍結、F1=旧800を追加200歩、F2=旧400＋新400を追加200歩。全追加条件は延べ800提示、同M0 model/optimizer、同Tの初期RNG・800位置permutationを復元する。F2では400旧データを置き換えるので、Δ21は新規性だけでなくデータ組成の総効果。F1−F0は旧データの追加学習、F2−F0は新旧混合＋追加学習の総効果である。追加訓練の資源機会費用はこれらの等MD量差に含まれない。

## 保存・検証と限界

各モデルのrecipe/exposure/loss/checkpoint/timingのSHA、初期/最終model・optimizer・RNG digestをmodels.jsonに保存する。CPU報告監査は全16状態のF1/F2の初期model/optimizer/RNG/親checkpoint/200歩/800提示の一致、共通M0初期weight、全80checkpointの内容digestを再照合した。初期化やoptimizerの制御は、データを変えた後も同一なパラメータ軌跡を保証するものではない。

検証200は診断のみ、early stoppingや配方選別に使わない。loss低下、訓練継続、Top1変更を探索改善としない。200歩・少数データ・同一初期化M0は本輪の制御設定で、十分に学習された一般のCVAEや本格的オンライン学習への外挿は未検証。学習時間は[費用](cost-and-runtime.md)、内部/下流の変動は[乱数分析](randomness-analysis.md)を参照。
