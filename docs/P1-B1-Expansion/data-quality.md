# 品質・完全性・予定数

本輪は実行中で、全行列完了をまだ主張しない。期待値は8連続履歴/32区間・16状態/M0 16・追加更新64・推論80＋F0反復16・下流MD240。F0は状態ごと3本のみ。予定ID、成功、失敗、未実行、MD成功と解析成功を別に数える。

品質は既存R2の全原子対応・有限性・拘束/鎖/重原子距離・側鎖手性条件を固定して使う。失格フレーム、理由、温度/エネルギーは保存する。粗い異常がないことはpH/準備/十分な平衡の認証ではない。容量不足や未公開入力は停止し、重複で補充しない。

入力/成功出力/SHA、M0と新区間の時刻順、X/Z/W凍結、実DCD→選点→MD入力を監査する。最終的な原ファイル照合とserver/Mac双方backup SHAを別に残す。小規模証拠がGitHubにあることと原データ転送完了は別である。
