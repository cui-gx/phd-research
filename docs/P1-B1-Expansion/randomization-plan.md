# 乱数と実行順序

r=1..8、s=4/8、T=1/2、M=1/2/3。履歴seed=1600000100+r。M0初期化/学習seed=1600000001を全状態で共通。追加学習seed=1601000000+100r+10s+T。MDseed=1602000000+100r+10s+Mで、同状態の全条件/Tに共有。推論は固定2026102671。役割間のseedは別で、JSONに全対応を保存する。同じseedは異なる起点の同一軌跡を保証しない。

240行をPython Random(1603000001)でshuffleし、その中でr01-s4に属する最初の行を工程連鎖のため先頭へ移す。残りの相対順は不変。元ID、順序をCSVへ保存する。モデル学習順は根番号+状態+Tの偶奇でF1/F2を交互にする。計算が中断しても未完了IDの元順序で再開する。結果を見て順序やseedを変えない。

根級bootstrap用seed1604000001、10,000回。MDや学習用乱数と混ぜない。F0共有観測を複製してサンプル数を増やさない。
