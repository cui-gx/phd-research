# 学習乱数とMD乱数：識別できる変動とできない変動

2026-10-27、DERIVED。4 ns/先頭100 ps除外の平均幾何新規度[Å]を中心に説明する。全指標・全感度条件の原表は [randomness-decomposition.json](../执行证据/2026-10-26-b1-expansion/randomness-decomposition.json)。8履歴根、同根2状態、状態内2学習seed×3MDseedは異なる階層である。

## 操作と統計量

固定状態sで、D_tm=Y_F2,t,m−Y_F1,t,m とする。t=1,2、m=1,2,3。学習乱数を変えた行平均差は a=mean_m D_2m−mean_m D_1m。各学習条件でのMD変動は sd_m(D_tm)（標本SD、ddof=1）。残差は e_tm=D_tm−mean_m D_tm−mean_t D_tm＋mean_tm D_tm、RMS=sqrt(mean_tm e_tm²)。この量は学習とMDが組み合わさった非加法性を含む記述量であり、1セル1本なので純粋な交互作用分散と誤差分散を分けられない。

## 各臂と共有F0

F1/F2自身の行平均、行間差、MDごとの列平均、行内MD SD、残差は同JSONのquantity=F1/F2に全16状態分を保存。F0はquantity=F0でMD SDとunique_observations=3を保存する。報告用JSONのmain_noise_rowsにも64記録を収録した。F0には学習seed要因がなく、二つの対応ブロックに同じ3枝を使っても6独立観測にならない。

同じMDseedを異なる起点へ対応させても、二つの軌道が物理的に同じ摂動・同じ進行を持つとは保証されない。対応乱数は比較精度を必ず改善するという仮定を置かない。学習seedにはデータ順・dropout等の乱数効果が含まれ、F1/F2を同初期RNGに揃えてもデータ内容まで同じにはならない。

## 根と状態の変動

根平均Δ21の標本SDは0.3247 Å。これは状態内の有限seed測定誤差も含み、純粋な根間生物学的分散ではない。同根S8−S4は8/8で正、平均+0.6991 Åだが、状態の平均処置差とその推定不確実性、時点ごとの運用条件変化は別物である。[状態依存性](state-dependence-analysis.md)を参照。

F1/F2それぞれ15/16状態でT1とT2のTop1が変わる。モデルが乱数に敏感であるという記述であり、学習乱数だけが下流変動の主因だとは同定しない。2学習seedと3MDseedは精密な分散成分推定には少ない。追加seedやセル反復は本輪では実行せず、必要性は研究者が判断する。

[CPU再照合](../执行证据/2026-10-26-b1-expansion/report-review-statistics.json)は9,216記録の対応する平均・SD・残差を元セルから確認した。下流240本や保存1,920,000フレームを独立根とする検定は行っていない。
