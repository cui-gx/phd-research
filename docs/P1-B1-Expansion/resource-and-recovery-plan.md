# 資源・中断復元・保存計画

最新の本人GPU利用調整（期限なし）と今回の明示承認に従う。予約表を直接閲覧したとは主張しない。各サーバ会話・インストール・各科学タスクの直前にCPU/メモリ/GPUを再検査し、他者と競合/許可不明なら本人の新規投入を停止する。他者を停止しない。接続失敗はVPNを依頼して他原因の探索をしない。

単GPU単槽。論理CPU0制御、1/2 worker、数値スレッド2、タスクRSS16GiB。GPU全研究時間に人為上限なし。ただしMD1タスク1800s、学習/推論600s、CPU特徴/指標2400sを異常検出に使う。監督を1秒間隔、GPUメモリ/使用率/電力の診断もサンプリングする。GPU指定子プロセス起動から回収までを占有時間とし、kernel活動積分とは呼ばない。

## 容量の根拠と保護

今回開始時の実測：Pilot run642,952,374 bytes/28ns、派生art7,643,001 bytes、完全圧縮archive581,720,607 bytes。単純線形外挿は1,024nsで原データ約23.5GB、圧縮バックアップ約21.3GB。新しいpool複製/特徴/解析、環境約8GB、ログ余裕を加える。これは見積りであり実使用量を測り直す。本人の本run+art+環境+archive合計上限120GiB、同ファイルシステム最低空き100GiB、起動時空き約882GiB。各タスク前と監督時に容量/空きを確認し、超過なら本人のみ停止する。無制限ディスク許可ではない。

Macは開発/伝送/文書/SHAのみ、数値科学計算を代行しない。原データは根別に処理し、全240軌跡をメモリへ同時読込しない。最近傍距離はブロック計算し、同じA0 SHAへの厳密距離をキャッシュする。

## 永続性と復元

新規run b1-expansion-20261026、根/状態/条件/T/Mとattemptを不変IDで分ける。成功taskはrequestと全output SHA一致時だけ再利用し、上書きしない。未完了/失敗ディレクトリは保存し、新attemptへ同じ固定要求で復元する。resumeを科学結果の都合による再実行にしない。科学条件を変える修復が必要なら停止・研究者へ報告する。

制御器を本人プロジェクト内で切断耐性を持って実行し、各完了でstatus/イベントをflushする。根/状態/行列と保存ソースSHAに不一致なら停止する。STOP/資源競合は本人子プロセスだけを回収する。GPU無計算だけで利用許可を推定しない。

根別完了印、全予定/成功/失敗/未実行、原因とrequest/result SHAを保存する。元S1/S2/GQ/R2/Pilotと当時ソースは読み取りのみ。定期的に本人の本run領域だけduし、旧証拠のハッシュ基準表を開始前に保存、終了時照合する。

## バックアップと清掃

完了根を順次archiveへまとめ、SHAと項目manifestを保存する。大DCD/配列/checkpoint/原ログはサーバ本人領域と検証済みMacバックアップの双方に保持し、GitHubへ大データを上げない。転送はGPU占有と区別し、遅いVPN下でも未検証を完了扱いしない。必要な完全バックアップを双端SHAで確認してから本人登録環境/キャッシュだけ清掃する。原データを削除しない。共有driver/CUDA/system/global Gitを変更しない。

計画は先にpush/遠隔回読。実装・実機試験後の開始/途中/終了の実績と失敗を交接記録へ通常pushする。全承認範囲の評価・監査・日語報告・バックアップ・清掃後停止。B2/C正式予測/S3、追加根・追加MDは別承認。
