# 履歴と情報時刻の固定計画

各根の0–2→2–4→4–6→6–8 nsは同一OpenMM完全checkpointの連続列。最初の2 nsの品質確定後、旧データだけでM0_4を作り、その後2–4 nsを生成する。4–6 ns品質確定後、同じ未学習初期化規則からM0_8を別に作り、その後6–8 nsを生成する。S8にはS4の枝を一切混ぜない。M0_8は継続オンライン学習の再現ではない。

境界b=2000/6000ps。旧学習：(b−1900,b−400]から等間隔800異ID。検証：(b−300,b]から200。新：(b,b+1600]から400。F2旧成分は旧800の偶数位置400。時刻は保存ログの実値で、上端数値誤差はPilot同様1e-5 ps以下のみ許容、下端は厳密比較。新データの生成/公開はM0より後。フレーム・座標の重複で黙って容量を補わない。

P4/A0_4は根の0–4 ns、P8/A0_8は0–8 nsの100 ps以後合格全フレーム。0.5 ps出力順のglobal ID、元2 ns区間とlocal ID、全原子DCDへの写像を保つ。モデル/optimizer/RNG/データ/候補/コードのSHA、MD終了→品質確定→pool公開→M0/特徴/状態公開→選択→MD採用を実イベントに記録する。物理時間から壁時計を逆算しない。

訓練と候補の重なりはこのオンライン設定の一部で、汎化評価ではない。検証は同じ履歴の時間split。全8根は同一準備構造と初期化規則に条件付けた探索。根IDを全枝・状態・ラベルに保存し、将来の学習/評価では祖先根を分ける。本輪はC予測器用の最終確認集と宣言しない。

### 初回GPU前の実装明確化（2026-10-26）

新旧の所属は保存元2 ns区間/global frame IDでも制限する。境界bの旧側はID<b/0.5ps、新側はID≥b/0.5ps。時刻の微小な累積誤差で最後の旧フレームを新データへ混入させない。時刻原値は書き換えない。W/Xの過去・最近区間もこの排他的な元区間規則で分ける。物理窓、標本数、seed、全行列は変更せず、元指示の新旧分離を実装する明確化である。初回科学GPU計算前に再push/遠隔確認する。
