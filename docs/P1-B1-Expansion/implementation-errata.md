## `Z.model_data_age_ns` の実際の意味

ソースはこのフィールドへ定数2を保存する。実際には決定時刻tとM0構築の物理境界bの差、`t−b=2 ns`を意味する。優先名は「モデル構築境界後の物理経過量 / MD time since model-establishment boundary」。**最新の訓練フレームからのデータ年齢ではない。** 元フィールド名を黙って書き換えず、読者はこの訂正と共に読む。

最新訓練データの物理年齢は、決定物理時刻から旧学習IDの実際の最大物理時刻を引く別量である。境界b−400 psまでの学習窓を使うため、二つの定義は一致しない。本輪でこの別量を新しいC予測特徴として追加しない。

`model_publication_age_s`は実壁時計の公開後年齢で、上の物理nsと別である。全状態の構築境界後物理量は固定なので、この命名問題は今回のXの時刻内変動・MD処理・等MD量の対応差を変えない。ただし今後の正式C入力では適切な名称と定義を研究者が確認すべきである。
