# 科学代理指標の読み方

正確な式・尺度・単位は[事前指標契約](metric-contract.md)に固定した。325非局所Cα距離のdRMSD、状態ごとの共通A0全点への最小距離の平均/中央値/p90、ε1.5/2/3 Å×τ0/5 psの全6領域代理、Rg/Q8/主鎖角をそれぞれ保持する。CVAE latentで自己採点しない。

主表示は4 ns/前100 ps除外。0/200/500 ps除外、1/2/4 ns前置区間、100 ps窓、Rg/Q8/幾何距離の時間相関を感度診断として保存する。関連フレームやprefixを独立反復としない。

A0はS8の方が大きくなり、同じ未来構造でも最小距離は小さくなり得る。時刻間差を純粋な科学フィードバック効果としない。領域数は尺度/順序/支持時間に依存し、準安定状態数や蛋白質の発見価値ではない。指標が不一致なら全て報告し、都合のよい尺度で結論を揃えない。
