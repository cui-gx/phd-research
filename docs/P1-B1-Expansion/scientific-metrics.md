# 物理代理：数学定義と読み方

2026-10-27。以下は事前固定された操作定義であり、唯一の科学成果指標・平衡分布・準安定状態数を認定しない。[凍結契約](metric-contract.md)の数値は変更していない。

## 1. 幾何新規度 [Å]

28Cαの非周期座標r_iについて、P3={(i,j):j−i≥3}、|P3|=325、v_ij(x)=||r_i(x)−r_j(x)|| [Å]。

d(x,h)=sqrt(Σ_P3[v_ij(x)−v_ij(h)]²/325)、m_A0(x)=min_h∈A0 d(x,h)。同状態のA0は100 ps以後の合格履歴全点で、未来分枝を追加しない。Y_mean=mean_eligible m_A0(x) [Å]、中央値とp90も保存する。固定A0から遠い形状への接近を表すが、折り畳み・安定性・発見価値を表さない。剛体変換に不変、鏡像に不変、履歴密度・初期緩和・伸展に依存する。

## 2. 持続確認つき追加領域数 [領域]

2 ps間隔の適格観測を時系列順に走査する。固定A0からε超、かつ既追加代表からε超の点を候補代表とし、近傍での持続をτで確認して追加する。初点を無料で加えない。確認前に近傍から外れる・失格になる場合の再開始、履歴距離との境界、代表/確認indexは[実装](../../p1/server/gq_r2.py)のregionsを固定版で参照する。ε1.5/2/3 Å×τ0/5 psの6設定。τ5は離散2 ps観測のため最低6 psを要し、連続して5 ps留まったことを観測したのではない。

実装では距離≤ε＋10⁻¹⁰ Åを既知としpendingを解除する。新領域のpending代表からεを超えるとpendingを現在点へ置き換える。失格点または既定max_gap=1.01×正の時刻差の中央値を超える欠測間隔でもpendingを解除する。τ判定は経過≥τ−10⁻⁹ ps。観測が全て新領域側にあり、pending近傍に残ることを要求する。

順序とε/τと参照A0に依存するgreedy計数。別代表間が離れていても異なる熱力学状態を保証せず、飽和/代表性を保証しない。粗い閾値は細かい局所差を併合し、小さい閾値は短期変動を過剰に数え得る。事前に全6条件を固定し、今回の方向差を見て一つを採用しない。
