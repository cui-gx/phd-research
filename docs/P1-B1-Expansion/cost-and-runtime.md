## GPU診断の意味

[GPU-diagnostics.csv](../执行证据/2026-10-26-b1-expansion/GPU-diagnostics.csv)は約1秒間隔の全GPU利用率・メモリ・電力の算術診断。例：最初の履歴r01-h1-mdで101点、利用率算術平均87.0495%、最大566 MiB、平均96.2701 W。全GPU値は他プロセス・サンプリング間隔の影響を受け得る。kernel積算時間、当該taskだけの消費電力量、科学的利用効率と等しくない。worker CPU_sは子プロセスの記録範囲であり、サーバ全CPU使用時間ではない。
