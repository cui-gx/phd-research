# 失敗・修正記録

2026-10-26。初回GPU科学計算前の開発・配備記録。MDの科学的失敗と区別する。

- 私人共有リポジトリが許可リスト方式のため、新規計画/コード/小規模証拠のパスを追加した。原データは引き続き対象外。
- 生成CSVのCRLFがGitの空白検査に抵触し、初回計画commit前にLFへ統一した。種子・順序は同じ。
- サーバに残る旧Pilot解析の例外文言が最終公開版と異なり、最初の全ソースSHA照合で検出した。数値的には同一の文言校正版へ初回GPU前に合わせる。旧実行ソースと原データは別archiveに保存済み。初回と修正後のpreflight記録を残す。
- 全240枝の合成fixtureは統計集計/共有F0を検証する工程試験であり、実MD結果として扱わない。第一根の実工程検証は事前行列内の枝を使い、追加MDを生成しない。

科学実行開始後の失敗は別途原ログ/attempt/要求SHAと共に追記する。不利なF2結果は失敗ではない。
