# P1：科学反馈状态 C 与更新净收益 B 联合设计

2026-10-25｜设计交付，等待研究者与规划侧审查。起始共享版本：`950c4a2315847bab07e502552a9aa97d59801008`。

**CONFIRMED**：C 为当前主线；B 同步设计并按证据决定是否成为贡献；FSD-EY/1FME、OpenMM、既有 mdlearn CVAE、单 RTX PRO 6000 96GB 不变。服务器承担主要数值实验与测试，Mac 承担开发、管理、同步与轻量调试。

## 给研究者的六个直接回答

1. **C 可以使用 B 的数据**：B2 从同一决策状态得到更新与不更新的配对下游差异，作为 C 的净价值标签；B1 提供等 MD 量的机制标签。两种标签不能混用。必须在运行前保存决策前状态和来源关系。
2. **仍需独立状态来源**：复用 B 不等于复用同一条轨迹当许多样本。需要不同生成根的 campaign，并为最终验证保留完整未见来源。B 的开发分支可以训练简单解释模型，不能同时认证该模型。现有 S2 缺少这种独立性和下游标签。
3. **当前 S2 最多支持工程可行性、成本试测及选择变化**：4,880 帧不是4,880个独立实验；旧数据续训也会改变选择。既没有更新后的配对探索效应，也没有固定墙钟净收益，更没有 C 增量信息的证据。
4. **会使正式比较不可解释的缺失**：科学 MD/reseeding 协议、独立评价器及阈值、合法共同分支、完整发布时钟、独立来源划分、可接受差异与样本量依据。需要先解决这些，再增加策略数量。
5. **只能先检验一个假设时**：在科学资格通过后，优先做 B1 中“含新数据的匹配更新，相对仅旧数据的匹配续训，是否改变有效下游探索”的小规模诊断。它是 C 标签可辨识性的前提检查，不是把主线改为 B，也不要求平均收益一定为正。平均为零仍可能存在状态异质性。
6. **当前批准的是设计与记录**。S2 补充原批准范围保留，但本任务不自动恢复其执行；新 MD、GPU 训练、校准采样、B1/B2、在线状态策略以及 S3 均需独立批准。研究方向确认不等于参数或实验许可。
