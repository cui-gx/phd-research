# 科学成果评价资格与统计分析计划

2026-10-25｜PROPOSED，正式评价器尚未冻结。下述资格检查是入场条件，既有S2数值有限性和代码测试不替代科学合格。

## 1. 固定科学协议的先决事项

向速水老师提供原始1FME与unfolded输入的来源/哈希、DeepDriveMD固定版本配置、当前OpenMM版本、6段S2时间序列、11结构cutoff敏感性表、reseed代码和低维混叠实例，请逐项讨论：

1. unfolded结构如何生成，序列、端基、缺失原子/氢、质子化与目标pH是否有可追踪准备史？未知项不能凭PDB编号补全。
2. 当前温度、力场、GBn2及1nm截断是否适合“短时构象探索”这一有限主张？1nm/2nm/NoCutoff固定坐标能量/总力差不是动力学验证，NoCutoff也不是物理真值。
3. 每次坐标重播种、最小化、重新生成速度后应怎样局部松弛；什么帧可作为探索输出，什么帧仅用于过渡？不自动要求全局平衡采样，但必须排除准备伪影。
4. 哪些距离/接触变化属于可解释结构差异，哪些只是噪声、解体或高能异常？阈值如何从物理尺度和独立数据确定？
5. 1ns或其他片段长度内是否可能看到适合本问题的可测变化？如果不够，最小有效长度和总观察范围是多少？

固定协议应包含 atom mapping、forcefield/solvent、nonbonded方法及cutoff、dt、温度/摩擦、约束、精度、最小化、reseed、松弛/采样、失败规则及输入准备。协议未确定时，设计可以完成，正式效果实验不能开始。目的不是估计平衡态自由能或折叠速度。

## 2. 评价候选的精确定义

所有坐标先统一Å；当前非周期体系直接欧氏距离，不用minimum-image。N=28个Cα且拓扑映射通过时：

Rg_CA(x)=sqrt[(1/N)Σ_i ||r_i−r̄||²]，单位Å，等权几何回转半径，不是全原子质量加权Rg。

Q_long(x)=|P₄|⁻¹Σ_(i,j)∈P₄ I(||r_i−r_j||<r_c)，P₄={i<j,j−i≥4}，28残基时300对；无量纲，不是native-contact Q。候选投影ψ(x)=(floor((Rg−o_R)/Δ_R),floor((Q−o_Q)/Δ_Q))。U_grid(A)=|{ψ(x):x∈A,qual(x)=1}|，单位格。o、Δ、r_c待独立标定；不能通过正式策略排名选取。

独立结构检查：D(x,y)=sqrt[|P₃|⁻¹Σ_(i,j)∈P₃(d_ij(x)−d_ij(y))²]，P₃={j−i≥3}，325对，单位Å。它是内部距离RMS差而非对齐坐标RMSD。固定中心库C={c_k}只来自独立校准数据；若min_kD≤ε则分到最近中心（tie按固定ID），否则库外。U_lib(A)=访问中心数，或除以固定|C|的有限库比例；库外比例单列，不把每个库外帧当新状态。

Rg/Q容易混叠，dRMSD对镜像也不敏感，均不是完整结构身份。补充同格最大/分位D、二级结构/有符号二面角和手性合法性审查；物理非法镜像不能当新探索。投影和结构指标需分别报告，不能只保留对策略有利的一项。若有限库代表性不够，只能作诊断，不能作为正式主指标。

## 3. 资格验收矩阵

| 检查 | 方法/固定条件 | 通过依据与失败行动 |
|---|---|---|
| 刚体/重复 | 同帧旋转平移、插入重复帧、顺序置换 | 距离/集合结果在精度容差内不变；失败修实现，不调科学阈值 |
| 区分能力 | 独立专家标注或固定物理差异结构对；检查同格形状差 | 必须解释合并/拆分；S2约6.435Å同格差是警告，未有合格阈值 |
| 独立来源稳定性 | 校准根建映射，独立资格根只评估；不补库中心 | 库外率、结构分布、覆盖饱和曲线全报；容忍度由领域判断预定，不追求好看比例 |
| 阈值/间隔 | 物理合理阈值网格；同轨迹固定多个抽样间隔 | 结论对合法范围敏感时限制主张；不得用结果挑最优 |
| 时间相关 | 分根画Rg/Q/能量、停留时间与采样间隔 | 帧数不作重复数；不能用单一快速量的ESS认证全部构象独立 |
| 异常/准备 | 有限性、键/约束、手性、异常能量、每段松弛窗口 | 原始数据保留；资格阈值由领域审查/独立校准而非胜负决定 |
| 容量/饱和 | U对MD ns、帧数、墙钟及库外比例 | 每帧几乎都新或几乎立即饱和均需解释；评价失辨则停止策略比较 |
| 标签独立 | 评价不依赖被比较CVAE，测试不重建网格/库 | 泄漏则该正式比较无效，保留失败记录，另提新验证方案 |

当前S2补充的r0库对r1库外85.8–99.8%是特定阈值下的代表性风险，不能宣布体系本身无科学意义，也不能因此临时把库外合并/拆分来改变排名。即使新四根小校准通过，也只取得局部资格，不能认证整个蛋白构象空间。

采样不确定性方法依据 Grossfield 等的原始指南[§4–7](https://doi.org/10.33011/livecoms.1.1.5067)：短轨迹看似稳定不保证充分采样；相关性估计依观测量与稳态条件。这里采用其谨慎原则，具体门槛是本项目待审设计，不是该文给出的认证标准。

## 4. 独立单位、拆分和共享模型

最上层单位是独立生成根/campaign i；同根j个状态、r个seed块、多个h和分支都相关。相同准备坐标但独立随机流只能支持“条件于该准备结构”的重复，不支持广泛初态外推。由同一长轨迹截取的不同起点仍按同来源组；尽可能纳入经批准的不同准备来源，来源不足则缩小推断范围。

四类数据角色严格分开：校准（定义物理评价/质量规则）→资格留出（检验评价器）→开发（候选特征/阈值/基线调优）→最终确认（未见根）。S2已被反复查看，只可开发诊断或来源复核，不再充当盲验证。资格留出一旦用于改指标，即降为开发，需新的资格来源。

按祖先图划分，而非frame或state随机拆分；任何共享轨迹或由彼此数据更新的checkpoint导致同组。外部独立、预先冻结的公共模型不使所有campaign自动合为一根，但须把结论限定于该共同初值，不声称跨初值泛化。拆分方法借鉴[Athey–Imbens的诚实估计原则](https://doi.org/10.1073/pnas.1510489113)，这里的祖先分组和paired MD设计是项目提案，不继承其树模型保证。

## 5. B与C的统计目标

B：先每根、每状态求种子配对差d_ijr，再按预声明状态/时域权重求根级平均d_i。报告全部根点、均值/中位数及范围、失败率、实际成本和有效ns。正式样本足够时按根bootstrap区间或预定分层模型；不能bootstrap帧得到很窄区间。不同h是同根重复测量，主h及主对比事前固定，次要比较标探索性。

C：首先在预声明Z/W匹配层检查X的共同支持；若所有新颖性高状态都早、低状态都晚，则无法识别额外信息。采用低自由度回归/预声明粗分层，标签是B2配对差，而非单臂Y。对m₀(Z)、m₀′(Z,W)、m₁(Z,W,X)使用同样的按根嵌套开发划分；标准化、缺失值规则、正则化与特征选择全部在训练折拟合。

最终确认的增量量：I_C=平均_i[loss(d_i,m₀′)−loss(d_i,m₁)]，正值表示预测配对效应更准；loss主项候选平方误差（单位成果²），同时报告绝对误差和分层校准。实际按state预测再在根内等权汇总loss，不能先平均所有状态隐藏异质性。I_C>0不等于动作决策有价值；另检验预测符号/决策分歧及不确定区间，再申请H-C3。试验标签含MD噪声，精度天花板与seed重复性同时报告。

配对分支允许测量动作干预差，科学状态X仍是观察变量。不可将回归系数解读为“提高新颖性会造成收益提升”。多个状态阈值/多个h尝试须完整登记；最终只有一组事前声明主检验，其余探索性，不用最好p值作结论。

## 6. 样本量与失败处理

最小诊断的4根×2状态×2seed块不是充分功效证明，只用于估计配对方差、效应可辨性和成本。正式根数需先定义领域有意义差异δ（格或有限库单位），用根级方差s_d²规划精度，例如区间半宽目标w的近似n≈(1.96s_d/w)²；小样本用t修正、模拟/保守上界并预留失败，不能把这个正态近似当保证。C还需状态重叠与留出根，不能只凭B平均效应方差确定功效。

为避免无限追数，研究者须批准最大根数、总GPU/存储上限和固定中期检查点；不根据显著性随意续跑。若达上限仍宽区间，结论INCONCLUSIVE，不声称无效或等效。等效主张须事前δ及完整落入[−δ,δ]的可信范围。

行政失败（他人占用、连接/存储故障）保留、按预定规则整配对重跑并保留原记录；科学失败（非物理状态/数值发散）是方法风险，不静默删掉。最终同时给按固定质量规则可计成果、失败率和敏感性；缺失标签不能默认0或只分析成功分支。删失/重跑规则未冻结前不得正式分析。

## 7. 阶段失败条件

- 评价器无法分辨合理物理差异：停止B/C效用推断，先处理资格。
- F2/F1仅候选ID变、下游效果未可辨：报告选择敏感，不称有效科学反馈。
- F1解释F2全部可测改善：暂不支持新数据特有作用，仍保留优化效应。
- 更新成本太小且效应落在事前等效区间：缺乏该部署中的非平凡机会成本；置信范围宽则不足。
- C增量仅由时间/数据/W解释：相应C主张不支持，不换指标寻找正结果。
- 简单强基线与状态规则等效：不主张新调度算法，但可靠作用边界仍可报告。

任何通过均需研究者/规划侧确认；此文件没有将任何科学门槛标为PASS。
