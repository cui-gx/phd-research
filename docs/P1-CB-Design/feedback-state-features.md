# 决策前反馈特征与泄漏审查

2026-10-25｜候选均 PROPOSED，尚无冻结特征/阈值。目标是低成本、可解释的信息增量，不是先开发复杂预测器。

## 1. 时间边界

决策时刻t之前只有已经发布且资格通过的结构可进入特征。记录`input_available_at≤feature_start≤feature_end≤decision_at`；特征计算占用的时间和CPU/GPU成本计入后续在线政策预算。一次动作的分支开始之前保存唯一特征快照，不能在得知结果后重算并替换它。

开发时允许离线计算候选特征，必须标为`offline_diagnostic`，记录真实服务器成本。若将这些结果拿来声称在线policy收益，必须在实际决策路径执行并计费。成本预测模型/物理阈值/标准化器只在独立校准或开发根学习。

## 2. 候选科学特征 X

令φ(x)为固定、非CVAE的物理描述；P_old是旧训练池，P_new是上次更新快照之后已发布的新数据。集合采样规则、窗口W_n、距离尺度均在开发前记录。不同规模比较用固定容量子样本并保存seed/索引，不能把取样不确定性隐藏掉。

| 候选 | 定义与单位 | 科学解释/成本 | 主要反例与处理 |
|---|---|---|---|
| 新数据非重复比例 x₁ | 平均 I[min_y∈P_old D(x,y)>ε_x]，x∈P_new；0–1 | 新数据远离旧训练几何；非局部Cα距离矩阵，朴素O(N_new N_old P) | ε_x不是天然阈值；高能异常会假新颖；先质量筛选、固定容量、计CPU代价 |
| 新旧物理分布差 x₂ | JS(p_new,p_old)=½KL(p_new∥m)+½KL(p_old∥m)，m=(p_new+p_old)/2；用log₂为bit | 在固定Rg/Q网格上分布变化，范围0–1；直方图成本低 | 受网格混叠和时间自相关影响；同物理量不等于独立样本，不把JS作显著性统计 |
| 近期探索增量 x₃ | [U(A_t)−U(A_{t−w})]/q_w，格/ns | 最近固定MD量窗口内新区域出现速度 | 与最终U有机械联系；以W=当前覆盖控制，另用独立结构指标交叉检验 |
| 近期重复覆盖比例 x₄ | 近期合格帧落入窗口开始前已访问单元的比例；0–1 | 局部重复/停滞 | 可反映可达空间小而非模型过时；采样频率敏感，只做描述/候选 |
| 最近实际更新后的产出 x₅ | 已成熟历史窗口中观测的新增覆盖/MD量或墙钟 | 过去动作之后发生的事实 | **不是历史更新因果净收益**；反事实通常不存在，且受旧policy选择偏差。最小C设计默认不纳入 |

ε_x、网格、窗口长度、子采样容量、伪计数规则（若使用）全部待审批。JS对空类别采用0log0=0；不需要为了有限JS任意加平滑。若空新数据集则特征缺失并记录，不设为0伪装重复。x₁与结果dRMSD共享表示时须披露，不能称完全独立测量。

最小候选面板优先x₁、x₂二选一或同时最多两项，加x₃作为敏感性分析，避免少量独立根拟合许多自由度。选择哪项在开发数据和计算可行性下固定，不根据最终测试胜负更换。

## 3. 系统/训练特征 Z 与覆盖控制 W

| 类别 | 变量 | 可用性与控制 |
|---|---|---|
| 预算 | h、已消耗墙钟、已完成MD ns | 秒/ns分别记录；h不是科学特征 |
| 成本 | 历史/独立profile的ĉ_up、ĉ_infer、ĉ_MD、估计不确定性 | 决策前模型版本和训练来源；本次真实c不能回填 |
| 年龄 | 距上次模型发布/采用的时间、其后MD ns、未纳入模型的新帧数 | 不同年龄语义分别记录，避免用一个age混合 |
| 数据/训练 | 旧/新独特帧数、曝光量、累计optimizer steps、train recipe ID | 这些可能解释全部X关联；必须进入匹配/分层设计 |
| 当前覆盖 W | U_initial、外库比例、已访问有限库比例（若库合格） | 在C分析中控制机会空间；若用于policy需算实际观测成本 |
| 技术条件 | batch、L、CPU配额、冷/热启动、GPU环境版本 | 单正式区块固定，条件变化另分层；不使用campaign ID作预测特征 |

主比较m₀(Z)→m₁(Z,X)回答是否有科学信息增量；更严格m₀′(Z,W)→m₁′(Z,W,X)检验X是否仅代理当前覆盖。若只第一组有增益，结论须收缩为“当前探索程度有信息”，不能说新反馈的独立作用。W过细导致无可比样本时应报告不可识别，不以过拟合残差造证据。

## 4. 禁止免费进入更新前判断的信息

| 信息 | 原因 | 合法用途 |
|---|---|---|
| updated checkpoint的LOF、latent、候选变化 | 先完成更新才能得到 | B机制分析；若探测更新须作为另一个付费动作审批 |
| F/U反事实配对收益、未来覆盖或最终构象 | 当前动作之后/未执行动作的结果 | 监督标签和离线评估，绝不能当本次X |
| 本次训练实际耗时、实际结束时剩余时间 | 动作后变量 | 成本结果、预测误差；不是主条件特征 |
| 测试集最优阈值、最终胜者策略 | 评价泄漏 | 禁止参与模型/指标选择 |
| 对所有验证分支预先训练的公共checkpoint | 测试源已进模型 | 不合法；重划分或另生成验证根 |
| 原始native RMSD | 当前目标不依赖天然参考选择 | 保留忠实复现基线和事后物理诊断，不能暗入主要决策/成果排序 |

若未来使用历史反事实标签训练一个价值预测器，其标签必须来自**事前独立实验库**，训练/获取成本单列；这与在线“历史观察到的产出”是两回事，本次不要求实现。

## 5. C分析接口

一行不是一帧，而是`root_id/state_id/horizon_id`及其成对动作结果；重复seed作为行内/层级重复。X/Z/W表在分支运行前锁定，结果表在运行后生成，join只用不可变state ID。检查空值、单位、来源哈希、时间顺序与split祖先交叉。若某特征无法在决策前以可接受代价获得，移至诊断附表，不以“以后可预测”宣称可部署。
