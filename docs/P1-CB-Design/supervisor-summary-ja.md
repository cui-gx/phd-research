# P1研究計画：科学的フィードバック状態とモデル更新の正味価値

2026年10月25日｜研究計画案。新たな実験結果の報告ではありません。実験条件・評価基準は未承認であり、S3には進みません。

## 研究対象と目的

FSD-EY（PDB: 1FME）を対象に、OpenMMによる分子動力学計算と既存のmdlearn CVAEを組み合わせます。既に動作を確認したDeepDriveMDの科学計算関数とParsl適応層を利用し、RTX PRO 6000 96GBを1枚使用します。現在は1 worker・1実行スロットでMDと学習を排他的に実行します。これは実装上の条件であり、単一GPUで並行実行できないという意味ではありません。

目的はタンパク質の天然構造予測や新しいCVAEの開発ではなく、限られた計算時間内の構造空間探索です。主課題Cは、**計算コスト、残り時間、データ量、学習履歴だけでは説明できないモデル更新の価値を、更新前に観測した科学的フィードバック状態が説明できるか**を検証することです。更新の正味価値を測る課題Bも同時に設計しますが、結論は分けて評価します。

## 既存研究との関係

DeepDriveMDは同じFSD-EYのMD–CVAE連携とサンプリングを既に扱っています。Colmenaは学習と科学計算の競合や古いモデルを使うか更新を待つかという問題を扱い、Ekyaも限られた時間内の学習コストと利用可能な時間を考慮しています。そのため、単一GPU、更新時機、残り時間という概念だけを新規性とはしません。

今回検証したいのは、科学的な計算条件と候補選択法を固定した上で、更新前の状態によって**更新した場合としなかった場合の成果差**が変わるか、その情報が強い時間・コスト基準に追加的な意味を持つかです。形式化そのものを新理論とは位置付けません。新規性と効果は、まだ実証されていません。

## 実験案

第一に、同一の合法な分岐状態から、①CVAEを固定、②旧データだけで追加学習、③新データを含めて追加学習、の三条件を比較します。②と③では初期モデル・optimizer、最適化ステップ数、サンプル提示回数を揃え、三条件で同じ候補集合、選択法、後続MD量を用います。全条件で座標からの再開始・最小化・速度生成の規則を揃えます。これにより、単なる追加最適化とデータ更新の作用を区別します（B1）。

第二に、同じ残り実時間の中で、MDを継続する、直ちに更新する、MDを1区間実行してから更新する、という行動を比較します。学習、推論、データ準備、モデル公開、タスク切替の時間を含め、期限までに利用可能となった適格な構造だけを数えます（B2）。現在の実装では期限後に実行中タスクが終了するまで待つため、評価時間窓と排空を含む実際のGPU占有時間を別々に報告します。

このB2の対応づけた成果差をCのラベルとして再利用します。入力は更新前に利用可能な物理特徴とシステム情報に限定します。更新後の候補変化や未来の構造を、更新前の判断に無料で使うことはできません。まず簡単な特徴と低複雑度の解析で検証し、追加情報が確認された場合だけオンライン規則を検討します。

## 現在の証拠と未解決点

S1の実閉ループは受理され、S2は条件付きで受理されています。S2の4,880フレームと補充解析は、実行可能性、限定的な時間測定、候補選択の変化を示しました。しかし、更新後の探索改善や正味利益はまだ示していません。補充検証の独立最終審査も未完了です。

評価指標には課題があります。高次元の接触パターン数はほぼ毎フレーム増加し、低次元の回転半径・接触率の投影は異なる形状を同じセルにまとめる可能性があります。固定構造ライブラリも別の軌跡に対する代表性が不足しています。したがって、物理的な意味、閾値、異常構造の扱い、独立データでの安定性を先に確認します。フレームを独立実験とは扱わず、独立生成元を単位として解析・データ分割します。

速水先生には、展開初期構造の準備履歴、プロトン化、GBn2とcutoff、座標再開始後の緩和、適切なMD区間長、物理的に解釈できる構造差について相談したいと考えています。現在の短時間結果だけで物理モデルの妥当性を保証することはできません。

## 実行範囲と判断基準

今後の数値実験と検証は原則として研究室サーバで行い、Macは開発・整理・同期に用います。他の利用者と予約状況を毎回確認します。本計画では新規MDやGPU学習を実行していません。

最小B1診断案は4生成元×2状態×2乱数ブロック×3条件で、後続MDは48区間です。これは変動と実行コストを調べる規模であり、統計的に十分な最終検証とはしません。実際の区間長、学習条件、資源上限、最終検証の生成元数は科学的資格と費用を確認してから承認を受けます。

更新が候補だけを変えて物理的探索を変えない場合、旧データの追加学習で説明できる場合、あるいは固定周期更新と共通の期限保護で効果を説明できる場合は、その陰性結果を残します。状態特徴が平均予測誤差を減らしても行動選択に影響しないなら、スケジューリング上の価値があるとは結論しません。まずこの限定された条件で説明可能な結果を得ることを優先します。
