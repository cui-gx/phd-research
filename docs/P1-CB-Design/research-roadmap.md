# 研究路线、失败后的收缩与外部适用性

2026-10-25。C主线、B联合设计优先级 CONFIRMED；下述篇章和后续研究均 PROPOSED。

## 1. P1可以成立的证据链

物理协议可解释 → 独立评价器有分辨力 → 合法同状态更新对照 → 等MD量科学作用 → 等墙钟净价值 → 未见来源中科学状态的增量 → 有必要才做在线规则。

这不是要求每个平均效应都为正。更新可能因状态而好坏不同；严谨研究也可找出何时简单固定更新足够。前置资格失败则后面再漂亮的策略曲线也不可信。

| 结果组合 | 可讨论的论文贡献 | 不可主张/下一步 |
|---|---|---|
| B2存在可解释净效应，C1/C2及在线验证成立 | 一篇围绕“科学反馈状态的增量决策价值”的论文；B为标签、机制和成本证据 | 不自动拆成两篇，不宣称最优/跨集群普适 |
| B成立，C在足够精度下无增量 | 固定配方下更新作用和机会成本边界的经验研究 | 不能硬写科学状态调度新算法；需评估相对既有工作发现是否足够独立 |
| C可预测大小，所有状态同一动作最优 | 动作效应异质性发现 | 尚无是否更新的控制价值；延后/频率价值需另证 |
| B平均接近零，C存在正负异质性 | 状态条件的重要性可能是主贡献 | 必须独立确认，不能事后切分挑正群体 |
| 选择变化有，但B/C都不确定 | 复现/诊断与测量结果 | 不称科学改进；精度不足与无效区分 |
| 评价/物理协议不合格 | 科学资格问题报告 | 暂停效用比较；不能换指标造正结论 |

两项互补贡献可在同一论文分别成章。只有未来各自具有独立问题、独立方法/实证广度和新知识、无数据切片重复发表风险时，才讨论两篇；目前不固定篇数和投稿级别。

## 2. 先保留FSD-EY，按诊断决定是否扩展

默认保留1FME。若很短MD只测重新松弛，先请领域专家给出合理片段/准备协议；不因当前74秒量级就换蛋白。如果科学合格训练几乎免费，只能说明这个部署的成本区间；不得无意义增加epoch或人为限速。

提出第二体系需要满足至少一项有证据的原因：当前可承受观察范围内独立物理成果不可辨；科学有效更新没有可研究的成本/动作差异；或已得到清楚结果而需检验跨物理动力学条件的外部效度。先报告原体系阴性/边界，再提出新批准。

| 方案 | 科学用途 | 所需证据/成本 | 对已有结果影响 |
|---|---|---|---|
| 1FME合法L网格 | 区分反馈频率、松弛和初始化比例 | L/松弛域资格；新任务另批 | 可保持对象，但不同L和有效ns须分层 |
| 外部1FME结构数据 | 检查物理描述分辨力和覆盖库代表性 | 文献R01/R02有长时显式溶剂资料；实际数据许可/文件/映射须核实 | 只能辅助结构资格；不同Hamiltonian/温度不能合并当同分布真值 |
| HP35/villin候选 | 检查另一已研究蛋白上状态—更新作用是否类似 | 必须明确具体序列、变体/PDB、原始轨迹、许可、准备与力场；本次均未批准 | 原S1/S2不可当HP35数据；CVAE输入尺寸、权重及LOF需重新资格 |

Bhowmik 2018与Lindorff-Larsen 2011提供villin相关方法/轨迹背景，不能据此宣称本项目已经取得HP35数据。D. E. Shaw Research[官方资源页](https://www.deshawresearch.com/resources.html)可定位原论文，本次未确认可直接下载哪组轨迹或许可。HP35不是唯一序列标识，本次不猜PDB。28残基接触输入到其他残基数可能涉及网络尺寸/预处理迁移，旧checkpoint不能默认兼容。

第二体系的价值应来自可独立解释的物理状态和泛化检验，而非“更大所以训练更慢”。不增加新模型开发作为P1前提。

## 3. 三年方向如何衔接而不膨胀

P1当前交付目标是单槽、单工作流内可审计的更新动作价值规律。若证据支持：下一候选可研究历史信息预测更新的潜在收益、成本及兑现时域；再以后才研究多工作流/异构GPU共享时怎样使用这种价值与性能信息做资源分配。每一步都重新检查既有文献、科学场景、资源许可和可验证目标。

预测的主要对象仍是“新数据到达后是否值得更新及其后续价值”，**不是自动改成预测集群作业到达率**。单卡结果不证明跨GPU响应曲线、MPI弹性或多用户调度价值；后续需要新的测量及公平共享指标。

长期三篇核心、视成果扩展四至五篇的意向保留；本次不指定P2/P3具体分子、算法、标题或投稿时间。当前先确保一个实验问题运行得出、解释得清。
