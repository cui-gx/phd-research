# 研究问题、假设与估计目标

2026-10-25。方向优先级 CONFIRMED；本文件的形式化和检验方案均 PROPOSED。全文术语对应[项目词汇表](../../教程/研究规范/术语与定义.md)。P1-C/P1-B 不等同于 S2 补充报告的任务 A/B/C 编号。

## 1. 可执行研究边界

对象固定为 FSD-EY/1FME 的 OpenMM→接触输入→既有 CVAE→候选选择→坐标重播种 MD。复用已有 DeepDriveMD 科学函数与 Parsl 适配，不声称已复现全部 Colmena 编排。当前一块物理 GPU、一个 worker、一个互斥计算槽；单 GPU 本身不禁止并发，单槽是本实验部署约束。

控制层仅研究**何时执行同一已合格的模型更新配方**。科学力场、候选选择算法、训练配方、采样/重播种协议在一次正式比较中固定。调模型结构、改变选点算法、探索 GPU 并发不混入主对照。不研究蛋白折叠预测、自由能估计、新 CVAE 或全机构调度器。

## 2. 决策状态与成果

在合法决策边界 t，所有输入已发布、上一任务已结束，保存共同历史 b，包括结构、数据集、模型和优化器、候选池、已探索集合及祖先哈希。观察量分为：

- X：决策前科学反馈特征，如新数据相对旧数据的物理差异。
- Z：系统与学习条件，包含预估更新成本、MD成本、剩余墙钟 h、模型年龄、数据数量、累计训练步数。
- W：已探索范围和剩余可辨识空间等控制量，防止 X 只代理“已经探索多少”。W 不向最终策略免费提供不可观测信息。

设固定、独立、经批准的评价器为 Ψ，质量合格且截至时限可用的结构集合为 A。探索效用 U(A;Ψ) 的单位由评价器决定，例如固定物理投影的“格”，不得称全构象空间百分比。新增成果为 Y=U(A_initial∪A_new;Ψ)−U(A_initial;Ψ)，排除共同历史重复收益。初始集合在同一分支对内完全一致。

## 3. B1：隔离数据更新的下游作用

在固定后续 MD 物理量 q（ns）下，a∈{0,1,2}：0冻结；1仅旧数据匹配续训；2新旧数据匹配续训。定义：

Δ₂₁(q)=E[Y₂(q)−Y₁(q)]；Δ₂₀(q)=E[Y₂(q)−Y₀(q)]；Δ₁₀(q)=E[Y₁(q)−Y₀(q)]。

Δ₂₁控制优化步数和曝光量后估计**训练数据组成改变的总效应**，不自动等于“信息新颖性”的纯效应。分布、重复程度、质量等仍共同属于该数据干预。Δ₁₀检查额外优化本身；Δ₂₀是整个更新包的效果。B1 不计放弃 MD 的时间，不能称净调度收益。

## 4. B2：固定墙钟的动作价值

使用相同 elapsed horizon h（秒），分支依次占用同一 GPU，不要求在同一个现实钟表时刻同时结束。U=立即更新一次，F=使用冻结模型继续 MD，D=先执行一个合格 MD 片段再更新一次。之后遵守共同固定续行规则 π₀，不允许各臂任意再更新。

τ_UF,h(x,z,w)=E[Y_U(h;π₀)−Y_F(h;π₀) | X=x,Z=z,W=w]。

同理定义 τ_DF,h 和 τ_UD,h。U 的训练/推理/发布成本减少其 h 内可完成 MD 的机会，**已经通过 h 内成果体现**；不再从构象数直接减去秒数，也不把利用率当成果。估计的是指定状态来源分布、配方和续行规则下的局部动作效应，非全局最优策略或自然蛋白机制。

Z 的成本必须是决策前独立 profile/历史估计 ĉ，不能主分析控制本次实际更新耗时 c_U（它是动作之后的变量）。实际成本用于成本核算、预测误差和解释性敏感分析。

## 5. C 的三项假设与反证

| 假设 | 需要的证据 | 反证或不足 |
|---|---|---|
| H-C1：可比 Z/W 下，X 对应不同动作价值 | 跨独立根的配对 τ，覆盖相近成本/时间/数据量下不同 X；重复随机性 | 分层后效应消失；无状态重叠；只在一个根或一个seed存在。无重叠是不可识别，不是“无效” |
| H-C2：X 对强基线有增量 | 同来源划分、同调优预算，m₀(Z,W) 与 m₁(Z,W,X) 在未见根上的动作效应预测误差差及效应量 | 增益不稳定/落在预声明等效范围；只来自当前覆盖量、epoch或时间。精度不足只能 INCONCLUSIVE |
| H-C3：状态信息值得进入在线规则 | C1/C2后，再独立批准比较简单状态规则与调优固定周期+统一截止保护/系统规则，计算特征成本 | 预测误差变小但动作从不变化；变化不改善同预算成果；强基线解释全部收益 |

不同 X 的关联性异质效应**不是对 X 本身的因果干预证明**。平均 B 收益接近零不否定 C：正负子区间可能抵消；平均 B 很高也不证明 C：所有状态可能同样应更新。若所有 τ 均同号且远离决策界，即使能预测大小，也可能没有“是否更新”的调度价值。
