## 最少需要研究者/领域意见决定的事项

1. 接受NoCutoff/GBn2作为哪个有限科学主张的实验模型？补足或明确接受准备史/pH未知的限制，选择可解释的局部松弛/采样规则。可将本报告与输入/电荷/端基、各force分项差、质量曲线交速水老师讨论；本轮按用户批准无需等其答复才完成探索。
2. 成果是粗Rg/Q投影探索，还是更全面结构探索？若采用前者应准确命名、限制论文主张；若采用后者，需认可独立结构/二面角尺度及库外处理。不能按哪个模型赢来定阈值。
3. 在NoCutoff的新合格数据上确认CVAE训练配方和无native选择规则。旧S2池的成本资格不能替代该科学资格，不混用不同物理配置数据制造反馈优势。
4. 冻结输入/祖先、种子、步数/曝光、reseed与松弛、同MD量和截止规则；完成最小分支恢复/发布测试，再申请B1。
