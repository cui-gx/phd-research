# GQ第1回：FSD-EY科学計算プロトコルと評価方法の予備検証

2026年10月26日。探索的な資格検証の報告です。モデル更新による探索改善や、スケジューリング手法の優位性を検証したものではありません。

## 実行範囲

FSD-EY（PDB: 1FME）、OpenMM、既存mdlearn CVAE、RTX PRO6000 Blackwell Max-Q 96GBを1枚用いました。研究者が承認した累積GPU占有時間60分の範囲で21タスクを実行し、実際の使用量は928.696秒、約15.48分でした。残り約44.52分は使用せず、本ラウンドを終了します。B1/B2/Cの効果比較とS3は未承認です。

既存S1/S2データを保存し、新たに3条件各100ps、4乱数系列各1ns、その後同じ系列をcheckpointから各3ns延長しました。主要4系列は各4ns、全MD量は短い試行を含め16.3nsです。4系列は同じ展開初期構造に条件付けた反復であり、独立した初期構造集団ではありません。

## 物理設定

Amber14とGBn2、300K、2fs、非周期条件を固定し、1nm、2nm、NoCutoffを比較しました。固定座標における1nmとNoCutoffの総力差は約0.17–0.22%でしたが、通常の非結合項では約13–18%、GB項では約24–30%でした。総力の小さな差だけで各近似を妥当と認定できないことが分かりました。NoCutoffも物理的真値ではありません。

事前の優先順位と短時間安定性・性能条件に従い、NoCutoffを今回の探索候補に選びました。4nsまでの計算で有限性、ペプチド鎖の距離、サンプリングした立体化学、拘束距離に明らかな破綻は見られませんでした。平均温度は約300Kでした。ただし、展開構造の作製履歴、pH・プロトン化選択、十分な緩和の有無は未検証です。平衡分布や折り畳み機構については結論できません。

## 構造変化と評価器

内部Cα距離とbackbone二面角には変化があり、単なる剛体移動では説明できません。一方、初期構造の緩和・圧縮を含む可能性は残ります。100psを除外した固定Rg/接触率投影の訪問セル数は、1nsで8/8/10/7、4nsで13/11/14/10でした。これは同じ軌跡の前後であり、独立比較ではありません。

評価器には依然として問題があります。同じ二次元セル内でも構造の内部距離差が最大約8.53Åとなり、異なる形状がまとめられています。校正系列で作った細かい構造中心集合は留出系列をほぼ覆いませんでした。半径4Åの4ns校正集合では、一方の留出系列の集合外率は約2.9%に下がりましたが、もう一方は約56.0%でした。良い方だけを選んで合格とは判断しません。

Rg/接触率は粗い物理的投影の記述には使えますが、構造空間探索全体の唯一の成果指標としては、まだ十分ではありません。フレームを独立標本とした検定や、未確認の平衡有効標本数は報告していません。

## CVAEのコスト

既存S2の800フレームを固定し、同じ初期checkpointから追加1epochと5epochを各2乱数系列で試しました。学習プロセスのGPU占有は約3.5–4.1秒と5.5–5.6秒、別プロセスの推論は約3秒でした。数値は有限でしたが、十分な学習や科学的な候補選択の有効性を示したものではありません。モデルが選んだ構造から新しいMDを実行していません。

## 次の判断

単一GPU上の実行と短時間の数値安定性については前進しました。次は、準備・緩和条件と成果指標の意味・分解能を確認し、固定した評価プロトコルを審査することを推奨します。その後に、更新が後続MDの成果を変えるかを調べる最小B1診断を別途承認していただきたいと考えています。現時点では、その実験やS3へ自動的に進みません。
