# 运行前实现细化与修订

2026-10-26，v1计划后、首次科学计算前。状态：本轮授权内探索性实施细化，不升级正式科学参数。

1. CUDA启用`DeterministicForces=true`以减少技术重复噪声，保留mixed精度；不保证随机动力学逐位可复现。旧S2未开启同属性，跨批差异不能全归因cutoff。
2. GPU控制器固定唯一`runs/gq-r1-20261026`账本，任务启动前按timeout+15s预留，完成后以真实spawn→reap占槽结算；pending任务阻断后续，避免重启重置预算。CPU分析不持有GPU上下文。
3. 同坐标检查每次显式设置坐标并applyConstraints，保存校正量；4组力为total/nonbonded/GB/rest。它测的是约束投影后的固定结构，不能和旧CPU未同样投影的数值直接逐值等价。
4. 延长顺序明确为seed11→13→12→14，先覆盖一对校准/留出，按预算最多5ns总长/根。不因探索结果优劣调整。
5. 新GQ诊断使用薄的有界子进程执行器与既有科学组件；不是另写工作流调度系统。正式MD–CVAE政策仍使用既有Parsl适配，未变更/认证。

## GQ3保守批次预算修订（首次延长前）

自动审批拒绝了4项各350s的批次，因为表面最坏总额1400s超过GQ3的1200s上限；虽然控制器逐项准入会阻止超支，仍改为更明确的安全方案：固定11→13→12→14，每根额外3ns、累计4ns，每项timeout270s，加每项15s余量总额1140s≤1200s。该被拒命令未执行，GPU消耗0s。无新授权申请，不借其他阶段额度，不按探索结果选根。4ns是原最多5ns内的收缩，之后不再自动补到5ns。分析相应报告原1ns冻结库外推与4ns校准库，尺度阈值不变。

## AI成本资格接口（首次AI运行前）

原science适配把MD参数与训练epochs放入同一config ID，直接改变epochs会与历史数据校验冲突。GQ成本测试保留历史MD记录/ID和全部SHA，不改旧记录；使用既有`freeze_snapshot`核验800帧S2池，复用固定mdlearn公共trainer/fit/predict与模型/优化器checkpoint接口，独立记录增量1/5epoch配方。绝对终止epoch=初始epoch+增量，checkpoint仅在最终epoch发布；不用增加无意义写盘制造成本。推理只算embedding+LOF，不依赖native排序，不启动后续MD。沿用已登记2seed/配方、最多4训练4推理。成本适用该固定小池，不证明合格学习配方、科学收益或新NoCutoff数据上的泛化。此接口和计时在AI前固定，GPU消耗仍由reserve唯一账计算。
