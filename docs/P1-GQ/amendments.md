# 运行前实现细化与修订

2026-10-26，v1计划后、首次科学计算前。状态：本轮授权内探索性实施细化，不升级正式科学参数。

1. CUDA启用`DeterministicForces=true`以减少技术重复噪声，保留mixed精度；不保证随机动力学逐位可复现。旧S2未开启同属性，跨批差异不能全归因cutoff。
2. GPU控制器固定唯一`runs/gq-r1-20261026`账本，任务启动前按timeout+15s预留，完成后以真实spawn→reap占槽结算；pending任务阻断后续，避免重启重置预算。CPU分析不持有GPU上下文。
3. 同坐标检查每次显式设置坐标并applyConstraints，保存校正量；4组力为total/nonbonded/GB/rest。它测的是约束投影后的固定结构，不能和旧CPU未同样投影的数值直接逐值等价。
4. 延长顺序明确为seed11→13→12→14，先覆盖一对校准/留出，按预算最多5ns总长/根。不因探索结果优劣调整。
5. 新GQ诊断使用薄的有界子进程执行器与既有科学组件；不是另写工作流调度系统。正式MD–CVAE政策仍使用既有Parsl适配，未变更/认证。

预计GPU消耗：本修订本身0s；之后每任务用持久账记实际值。任何进一步修复在此追加，保留失败目录及原始记录。
