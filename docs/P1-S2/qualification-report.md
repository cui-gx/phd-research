## 4. 科学设置与稳定性结论

6段有效轨迹均504原子，帧数/日志/坐标/能量/温度有限，无崩溃和约束求解异常。两段1ns平均温度300.9906K、300.4046K。**只通过基础数值稳定性检查**，未证明平衡、充分探索或参数对FSD-EY科学问题的充分性。

需保留的风险：unfolded生成与质子化历史未完整提供；没有独立平衡/burn-in；原隐式溶剂1nm截断误差未量化；restart只传坐标并重新最小化/生成速度，不是动力学continuation。盒子确实传入上游接触分析，但本批4880帧有盒/无盒计算与保存矩阵完全一致；潜在语义问题没有在本样本造成实测差异，不能宣称已发生污染。

## 5. CVAE更新确实改变了候选选择（MEASURED，单次可行性）

先以第一段200ps的400帧训练现有CVAE 1epoch；冻结其checkpoint。第二个模型通过原mdlearn公共checkpoint接口恢复同一模型和RMSprop状态，用两段共800帧继续1epoch（保存epoch2）。模型种子2026102403；两个模型对**同一800帧、同一顺序、同一特征、同LOF k=20/N=100**推理，种子2026102404，每个模型重复2次。

- 共同初始checkpoint哈希核实，冻结checkpoint未修改；更新前后模型权重L2差11.04218，epoch1→2，模型/训练快照/候选快照链保留。
- 两个模型各自重复推理的嵌入与LOF分数逐值相同。
- LOF最异常100帧短名单仅19帧相同，Jaccard=19/181=0.104972；800帧LOF分数Spearman=0.120153。
- LOF-only首选从第一轨迹frame53变为frame138；这只是一项诊断，未替换实际选择规则。
- 实际LOF→参考RMSD规则下，最终首选从第二轨迹frame340变为frame365（0-based）；参考RMSD数值保持不变，参考本身未变。两者诊断RMSD为6.1599Å与6.0942Å，**不是本研究的探索收益指标**。
- 参考RMSD单独排序的首选为第二轨迹frame363，与这两次结果均不同；说明本例LOF筛选有实际影响，但最终选择仍是参考引导。

支持的结论：在这个有界配对样本中，现有CVAE更新能够改变下轮起点决策。**不支持**：新数据单独导致变化（与额外训练/数据划分/优化步骤尚未分离）、更新平均更好、不同候选带来更多探索、更新频率/调度优越性。未从这两个新起点开展后续收益对照；不在S2强求显著性。

## 6. 覆盖指标：可计算，但当前状态划分不能直接用于正式比较

独立非周期Cα距离325对，预先规定接触阈值8Å、分箱宽度1/2/4Å。4880帧产生4859个接触指纹、4880/4879/4879个距离分箱状态；重复输入不增加计数，计算测试通过。

**这一结果是评价器的警告信号**：几乎一帧一个“状态”，更像记录采样数量和热涨落，不能解释成科学上不同的构象状态。两项草案没有达到可信科学分辨能力；需研究者/规划侧决定更稳健的固定物理状态划分或独立状态库。未按本批模型结果择优调整阈值或悄悄增加新算法。
