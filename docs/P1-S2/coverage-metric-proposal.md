# S2-D：独立构象覆盖评价草案与可计算性

日期2026-10-24。状态：**PROPOSED**；仅被批准设计和验证可计算性，指标与阈值没有成为正式论文协议。实现：`p1/server/qualification_analysis.py`；阈值在查看本次比较输出前写入 `configs/p1-server-s2-pilot.json`。

## 共同输入与物理表征

只读取通过完整性检查的1FME轨迹，按拓扑顺序取28个Cα。定义序列位置i<j且j−i≥3的325对Cα距离，单位Å。使用分子内**非周期**欧氏距离，不使用PDB盒子，不需要结构对齐；整体平移/旋转不影响结果。输入文件、帧ID、采样时刻、atom mapping、SHA-256均保留。

该评价器不调用CVAE、不需要训练集、不读取天然参考结构或RMSD，不使用LOF排名定义“新状态”。即使工作流选择规则暂时依赖参考RMSD，评价本身仍独立；这并不使参考引导的决策自动成为无监督选择。

## 候选一：固定接触指纹状态数

对每个上述原子对，以`distance < 8 Å`定义一个bit；325个bit组成完整指纹。指标为截至端到端时间t已访问的不同指纹个数`N_contact(t)`。8Å沿用当前接触特征约定作为PILOT，排除序列相邻对是评价草案；不改变训练输入。

没有外部状态库或天然参考构象。所有策略使用同一个原子对集合和阈值；重复相同帧不增加计数。**这不是全部可达构象的覆盖百分比**，也不是状态热力学稳定性或独立科学发现个数。边界附近的热涨落可能产生许多近似指纹；以后需独立校准或增加稳健性检查，不能按哪个策略效果好选阈值。

## 候选二：固定距离分箱状态数

将每一距离d映射为`floor(d / Δ)`，统一原点0Å；完整325维整数向量定义离散状态。分别预设Δ=1、2、4Å做敏感性检查，报告每个Δ的不同向量数`N_bin,Δ(t)`，不从本批结果选“最佳Δ”。无聚类拟合或随实验增长重新分配的类中心，无模型/外部参考集合。

高维完整分箱可能每个热涨落帧都变成新向量，导致计数接近采样帧数；若出现这种退化，必须报告而非包装成探索成功。当前只检查“可以计算、输入合法、重复帧不增计数、结果不全为1”；正式协议需结合物理解释、数据相关性与采样密度进一步审批。

## 公平性、计算成本和验收

- 单个文件可分块提取坐标，提取距离复杂度O(帧数×325)，保存特征后以集合/去重计数。当前验证还要读DCD、计算诊断RMSD相关上游特征；报告计时明确排除/包含哪些部分。
- 相同规则应用于每个策略；候选数、采样间隔、burn-in规则、种子、完整预算内截止事件在正式比较前冻结。不能把相关帧当独立统计重复。
- 正式P1可画累计状态数随端到端墙钟秒变化，同时报告实际模拟ns和采样帧数。相同数量帧下的补充检查可区分采样量与新颖性；S2没有策略效果比较。
- 检验：325对原子；平移/旋转不改变距离；输入非有限或形状错误拒绝；阈值边界遵守固定`<`和`floor`规则；重复同一组输入不创造状态；至少一组真实轨迹状态数>1。真实输入输出、实际计算耗时与局限在阶段报告及coverage-computability.json中记录。
- **等待研究者决定**：是否采用上述任一指标、如何抑制热涨落敏感性、是否使用独立预采样构建固定状态库、最终阈值/采样与burn-in。Codex不据S2试测自行批准这些选项。

## 小样本真实检验结果（MEASURED）

4880个真实PILOT帧均可计算325维物理距离。接触指纹去重4859个；距离分箱Δ=1/2/4Å分别4880/4879/4879个；复制同一批帧未增加计数。去重与重复检查耗时0.5690s，**不包括DCD读取、坐标/距离提取和其他诊断**。平移/旋转不变性和固定边界规则等测试通过。

这同时暴露出**实用性问题**：计数几乎等于帧数（接触99.57%，距离约100%），说明高维完整指纹/分箱过细，对热涨落及采样量过于敏感。不能据这些数字宣称发现4859个有科学意义的新状态，也不能直接冻结为P1主指标。当前两个候选仅通过可计算性和重复帧检查，**科学分辨能力未通过**。需要研究规划侧确定更稳健的物理状态划分/独立固定状态库/容差方案；本阶段未根据哪种模型更优挑阈值，也未追加新的正式评价算法。
