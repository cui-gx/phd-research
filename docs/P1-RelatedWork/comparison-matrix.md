# P1 研究差异矩阵（14 维，13 项研究）

2026-10-25｜有原文12项；只有元数据1项。预印本/正式版不重复计数。

**阅读规则**：I=作者已实现并报告评价（可能是真机、离线、代理模拟或理论，见各格）；P=提出但本论文未隔离实测；F=未来工作；N=本次没有找到充分证据，绝非不存在的证明；NA=不适用。文献报告结果不是本项目亲自 MEASURED。第13–14行是本审查的 `DERIVED / PROPOSED` 判断。

“没有剩余预算控制器”不能从“没出现deadline字样”推出：本表检查动作、目标、成本、停止规则和评价，允许跨应用等价问题。固定实验时长、固定物理MD时长、有限决策轮数和根据剩余墙钟决策分别记录。

## 汇总的适用范围

最强直接先例为 R03/R04/R05；有限时域与机会成本的强方法先例为 R06/R07/R10；科学状态引导下一任务的先例还有 R08/R09。R01/R02用于科学资格，不因其不做调度就称其有研究空白。R11防止把异步系统性能与科学效果混为一谈。R12只作为公开作者稿理论邻近工作。R13阻止过度的新颖性结论。

不存在某篇“全部14维都打勾”不自动证明P1新颖；应检验是否只是已有方法的直接组合/简化。正式论文仍需比本次检索更完整的最新补查。见[审稿反驳](reviewer-critique.md)、[检索边界](search-and-source-log.md)。
