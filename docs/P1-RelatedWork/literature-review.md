# P1：创新性、相关工作与研究问题独立性审查

2026-10-25（JST）｜证据类型：`derived analysis`｜研究判断：**PROPOSED，供研究者审查**。

本报告依据开始时 GitHub main `1dc4f85d6fae311b6ac8d56c3533c2ec981272c3` 的研究档案及研究者本次明确指令。研究对象仍为 FSD-EY/1FME、OpenMM、既有 CVAE、单 RTX PRO 6000 96GB；当前单 slot/单 worker 是实验约束。没有运行实验、访问服务器、修改科学实现或推进 S3。S2 补充的独立终审仍未完成，本报告不代替该审查。

## 摘要与判定

**广义思想的新颖性不足；受限条件下的独立实证贡献仍有可能，但现有证据不能确认。**

MD–AI 耦合、在线更新、旧模型与重训等待的取舍、有限资源下训练的机会成本，以及有限时间内兑现学习收益，都已有直接或跨领域先行研究。尤其应纠正“此前只有概念讨论、没有牺牲模拟时间换取科学成果的定量证据”这一表述：Colmena 2021 §IV-C2 已有此类结果。也不能用“其他研究没有固定 deadline”概括近邻：Ekya 在固定窗口内优化模型更新后的实际使用收益，ORRIC 的权重显式依赖剩余轮次。

P1 可以尝试回答的较窄问题是：**在明确的单槽执行条件和独立科学评价下，CVAE 更新相对继续 MD 的净探索效果，如何随当前数据/模型状态与剩余时间共同变化；简单的成本及截止规则已能解释多少，反馈状态是否还提供额外信息？** 这是一项待验证的经验问题，不是已成立的新调度理论。

推荐以严谨实证为核心，简单策略为条件性附加贡献；不把复杂预测器作为补救创新性的默认办法。若最终只得到不同固定更新间隔的性能排名，或优势完全来自避免截止前无用训练，则应降低为参数研究/案例报告。是否可投稿取决于证据与目标场所，不保证录用。

## 1. 检索与阅读方法

本次为有边界的证据审查，不宣称 PRISMA 式穷尽系统综述。以用户指定五篇为种子，向外追踪三类邻近工作：科学反馈和自适应采样、受限资源重训与有限时域决策、计算价值理论。检索日期、查询、纳入排除、读取深度、版本与失败详见 [检索及来源记录](search-and-source-log.md)。

纳入 12 项有原文的核心/邻近研究，另登记 1 项只有出版元数据的高风险缺文 DynaGene。每篇预印本和正式版合并计为一项研究。AL-Queue 与 Few Updates 没有据二手索引擅自认证录用。原文可用不等于全部附录、代码、原始数据都已审查。

标签约定：`I`=本文实现且报告评价；`P`=提出但本论文未隔离验证；`F`=未来工作；`N`=本次检查范围未找到充分证据；`NA`=问题不适用。`N` 绝不等于证明不存在。文献事实不使用本项目 `MEASURED` 标签冒充亲自复现。矩阵的定位见 [14 维比较](comparison-matrix.md)，书目信息见 [references.bib](references.bib)。

## 2. 科学基础：已有模型和物理对象不是创新

### R01 — Bhowmik et al., 2018

[原文](https://doi.org/10.1186/s12859-018-2507-5)，Methods / CVAE analysis of BBA / Fig.7 / Discussion。

CVAE 用接触图表示 Fs-peptide、villin 和 BBA 的构象。BBA 两条轨迹为 223 μs、102 μs；325 K、CHARMM22*、相容的显式 TIP3P。第一条用于训练及内部划分，第二条用于跨轨迹检查。Fig.7 以潜在表示、接触与结构解释区分折叠、中间和错误折叠构象。Discussion 明确没有验证这些方向是否就是可驱动折叠的反应坐标。

**对 P1 的意义（本审查推断）**：使用 1FME+CVAE，甚至跨轨迹表示验证，都不能作为新贡献。表示能解释旧数据，不自动推出在线更新能改善未来探索。当前隐式 GBn2/300 K 的短轨迹与该文物理设置不同；不能把其科学有效性直接转移。本次未取得 Shaw 原始数据，也未重新分析它。

### R02 — Lindorff-Larsen et al., 2011

[原文 DOI](https://doi.org/10.1126/science.1208351)，Science pp.517–520，Fig.1–3；可访问的论文副本及读取限制见来源表。

研究 12 种蛋白的折叠机制，使用 Anton、显式溶剂和长时轨迹。Fig.1 的 BBA/1FME 标注总模拟 325 μs、代表结构 Cα RMSD 1.6 Å、平均未折叠态寿命 18 μs；这些不是本项目的性能或目标阈值。正文比较折叠路径、结构形成次序和自由能屏障。本次核查了正文与 Fig.1 原图，未获取完整补充方法和轨迹。

**对 P1 的意义**：提供物理背景和外部检验候选，不是单 GPU 工作流调度先例。不能用“只测探索、不测折叠”回避准备/平衡资格，也不能因小蛋白容易运行就推断可在当前预算内重复观察有意义探索。历史长时数据若使用，必须审查许可、构象映射和不同势能模型的可比性。

## 3. 最直接重叠：DeepDriveMD 与 Colmena

### R03 — Brace et al., IPDPS 2022：DeepDriveMD

[论文](https://arxiv.org/abs/2104.04797v5)，§III UC1、§IV-A–E、§V-A/Fig.3、5、6、§VI-A/Table II/Fig.7。

FSD-EY、OpenMM、CVAE 及起点反馈均已有实现。文件模式按阶段串行，所列实验隔轮训练；流模式各组件循环、按数据流同步并接收新权重。UC1 的 ML+native-RMSD 选择与 ML-only、RMSD-only 等比较。覆盖采用外部 Anton 构象的 10 维 CVAE 表示及 500 个聚类状态。headline 加速以模拟时间衡量，不能换成等 GPU 墙钟加速。系统比较使用 30 对 33 节点，训练 epoch 等配置也不同；不能据此隔离单一更新时机效应。

**对 P1 的实质判断**：工作流、对象、反馈与构象采样效果均高度重叠，不能声称以科学成果评价是首创。可能差别在等容量单槽、等截止、固定选择算法下分离更新时间与被挤掉的 MD，但当前没有完成这种实验。论文的科学覆盖也并非纯生物学结果，已有明确系统效率论证。

另须区分版本：当前实现复用 mdlearn/PyTorch 科学函数及 Parsl 适配；该文 CVAE 为 Keras/TensorFlow，原论文运行基座是 EnTK/RADICAL-Pilot/ADIOS。相同名称不等于逐项复现相同系统或协议。

### R04 — Ward et al., MLHPC 2021：Colmena

[论文](https://arxiv.org/abs/2110.02827v1)，§IV-A–C，Fig.2–4。

NWChem 分子评估、MPNN 训练及推理共享节点；Allocator 在新增结果达到阈值后优先完成学习任务，其余资源运行模拟。256 节点比较 random、no-retrain 与 update-8；§IV-C2 报告更新方案**模拟时间少约 5%，高价值分子多约 10%**。它同时报告反馈平均延迟约 57 min。末尾提出更优资源划分及重设 worker 开销的研究需求。

**纠偏**：过去“没有系统搜索 simulation-priority/learning-priority 的最优配置”可以成立；据此推成“没有固定资源下机会成本与科学产出的定量比较”则不成立。本文已经提供后者的一个直接实例。仍未找到按剩余预算改变更新动作、并隔离反馈状态增量价值的充分证据。也不能把 update-8 的完整策略收益全部归给资源分配，队列排序同时变化。

### R05 — Ward et al., IJHPCA 2025（online 2024）：Colmena 后续

[正式全文](https://doi.org/10.1177/10943420241288242)，§4、§5.1–5.2、Fig.2、5、6、§6–7。

§5.2 明确陈述旧模型立即决策与等待训练的速度/质量取舍；异步训练、流数据和按需旧模型推理是所描述的实现策略。**Fig.6 是工作流示意图，不是比较收益曲线。** 该段科学加速引用 DeepDriveMD，不能重复计成独立对照。§4 有科学结果和资源时序，§5.1 有反馈更新导致暂停的实际例子；§7 的延迟测试是合成代理任务。

**对最高优先级问题的回答**：不能说 Colmena 只有想法而没有机制；它已有相关机制和应用证据。但在已核查正文，没有找到为 MD 每次计算“等新模型的净探索收益”，或利用剩余 wall-clock 决定训练/跳过的专门实测控制器。没有明确的 stale/new 决策质量评分公式可直接等同 P1 的独立探索指标。这里的未找到只是有限证据结论，尤其受 DynaGene 缺文约束。

## 4. 跨领域先行研究足以否定哪些宽泛首创主张

### R06 — Ekya，NSDI 2022

[正式论文](https://www.usenix.org/conference/nsdi22/presentation/bhardwaj)，§3.2/Fig.4、§4.1 Eq.(1)、§4.2–4.3、§5–6。

固定 GPU 与重训窗口内最大化平均推理准确率；联合选择训练/推理配置及资源，包含不重训。预测训练成本与新模型质量，利用窗口内剩余使用时间；窗口开始和训练完成时调度。真实 1/2 V100 评测与扩展规模 trace-driven simulator 并存，4×资源节省不能当作 16 GPU 真机结果。FixedRes/FixedConfig 消融分离部分机制。

**与 P1 的区别是结构，不是术语**：外部视频流不由“继续推理”产生，而 MD 动作改变未来训练数据和可选起点。P1 的终点覆盖也不等于窗口平均准确率。不过这些差别只说明 Ekya 原目标不能原封照搬，不证明改成科学收益函数就有新算法；必须比较其“成本+收益+时域”思想的简单适配。

### R07 — ORRIC，INFOCOM 2024

[论文](https://arxiv.org/abs/2405.16029v1)，§III Eq.(5)、§IV–V (Dt)/Algorithm 1、§VI/Table III。

在每轮资源约束下选择训练与推理配置，长期准确率模型以历史学习量表示，给出有假设的竞争分析。训练权重含 \(\sum_{\tau=t}^{T-1}1/\tau\)，因此已显式体现时域末端的训练价值下降。CIFAR-10-C 评价以 MAC 资源预算、模型配置及准确率为主，并非同一物理 GPU 上 MD 墙钟探索比较。

**判断**：剩余时间、可解释规则、当前工作对未来学习的取舍都不能泛称新。其凹增益/代理资源等假设没有在 FSD-EY 探索上成立的证据，竞争比不可直接移植。P1 若仅提出线性剩余预算阈值，方法增量很弱。

### R08 — AL-Queue，2025 作者稿

[论文](https://arxiv.org/abs/2509.25538v1)，Algorithm 1、§VI-B/Fig.3、§VI/Table II。

用模拟反馈更新 surrogate 并改变 MOF 队列次序。Fig.3 是已有稳定性标签上的 simulated search。完整工作流将 MD 分给 48 CPU、AL 分给 1 CPU，AL 约占总 CPU 资源 0.6%；另有 GPU 上的生成模型。作者明确承认尚远离每结果重训造成瓶颈的条件，并提出批量重训应对。

**判断**：已经覆盖内生科学数据→学习→未来选择的反馈。故“Ekya 没有内生数据”不是领域整体空白。P1 必须证明该耦合在等预算下引起值得解释的调度差异，不能只换成另一分子模型。本文的科学收益也不能全部归给资源分配；它改变的是队列优先级。

### R09 — REAP，J. Phys. Chem. B 2018

[论文](https://doi.org/10.1021/acs.jpcb.8b06521)，REAP Algorithm、Eq.(1)起、Results；所读作者稿 PDF pp.8–12 及后续评测。

以所探索构象学习反应坐标权重，再选择重启结构；比较长轨迹和 least-counts。模型势能面、alanine dipeptide 与 Src 案例并存；Src 使用既有 MSM 的 kinetic Monte Carlo，不能全部称新 atomistic MD。主要体现采样动作和状态相关价值，未找到将学习成本与 MD 占槽时间作固定截止对照的证据。

**判断**：科学状态决定下一采样动作已有丰富先例。P1 固定选择器后研究是否更新它，才可能分开“选择哪里”与“花多少时间更新选择器”；无学习的低占有率重启可作一个待审批诊断对照，不能未经批准替换 CVAE。

### R10 — Hay et al., UAI 2012

[正式记录及全文](https://proceedings.mlr.press/r10/hay12a.html)，§2 Definitions 1–3、§3–6。

将计算视为可付成本的元决策，以最终行动质量减计算成本为目标；明确可将时间/累计成本加入状态处理 deadline/budget。理论与采样/围棋案例均已有，不涉及本项目 MD。故“比较额外学习的价值和成本”及其 Bellman 形式都不是 P1 的原创理论。

**可借鉴而不可冒用**：P1 的 MD 既产科学结果又产学习数据，更新不是纯观测未知固定收益；代价也不宜以任意系数将秒和覆盖相减。下述形式化用同一剩余时间的两个完整后续过程定义差值，不冒称新定理。

### R11 — Pascuzzi et al., JSSPP 2023

[作者会议稿](https://jsspp.org/papers23/Pascuzzi.pdf)，§4–6、§6.1/Table 1、Table 3。

建模并实机评价异步异构任务执行。DeepDriveMD 形状的任务参数来自既有运行，但评测使用 stress 可执行程序并省略数据操作。它支持执行组织/资源利用分析，不能当作验证新候选的实际构象收益。

**判断**：通用异步 overlap 不是 P1 贡献；本项目单 slot 也不能靠搬用多任务重叠加速解释结果。需要的是科学因果链和准确账本，而非只增加一个调度器实现。

### R12 — Sima et al., 2026 作者预印本

[作者原文](https://www.cs.purdue.edu/homes/spa/papers/retrain2026.pdf)，§1–2、学习曲线假设及主定理。

以至多 S 次重训 oracle 调用和 T 个数据轮次研究累计预测风险；在限定学习曲线/数据假设下证明很少更新即可接近目标风险。该稿日期为 2026-01-29；本次 OpenReview 访问受限，未验证正式录用状态。更新次数预算不是实测墙钟成本；定理不能用于保证当前 CVAE 探索。

**判断**：仅声称“没有必要每次有新数据都训练”或设计倍增更新间隔没有足够独立性。P1 的困难是科学效用、内生数据和真实成本是否产生可复现边界，而不是重新证明少更新可行。

## 5. 高风险缺文与不确定性

**R13 DynaGene，IPDPS 2026**：DOI `10.1109/IPDPS65963.2026.00103`，出版社提交的 Crossref 元数据核实作者、题名、会议和 pp.1246–1259；IEEE 页面返回浏览器验证，检索没有取得可读原始摘要、结论、图或全文。不能从题名猜测它的目标函数、算法、科学收益或是否使用 deadline。它留在矩阵，全部机制项标 `N`，不是被排除成“不相关”。

本次没有完成所有后向/前向引用的全文覆盖，也没有审计上述所有系统的公开代码。报告可否定若干过宽首创主张，但不足以认证“世界上首次实现这个组合”。建议创新性表述继续使用“在这一明确实验约束下研究/量化”，待缺文核查和实际结果后再决定论文贡献。

## 6. 与现有工程证据的接合

[S2 报告](../P1-S2/qualification-report.md)证明真闭环、成本和一次候选变化；[S2 补充报告](../P1-S2-supplement/supplement-report.md)增加无 native 选择和匹配更新步数的有限对照。它们没有产生更新后的下游收益对照。当前物理评价库代表性不足、低维投影混叠、MD 准备/平衡未资格化，不能把它们当作已完成论文主结果。

S2 的 1 epoch 更新成本也不能当正式 CVAE 成本。不能为了制造调度难题而故意拖慢训练，再把注入延迟写成自然工作负载的发现。若额外延迟用于机制敏感性，它必须另行获批、单独标记，并以真实可达到成本为中心。
