# P1 问题形式化草案：在同一时间内比较更新与继续模拟

2026-10-25｜`PROPOSED / derived analysis`。本文件用于澄清问题和排除伪创新，**不是获批的实验协议或新算法**。固定对象以总档案为准；所有未知分布、阈值、预算和统计精度都尚未认证。

## 1. 最小研究对象与边界

| 项目 | 当前约束 / 状态 |
|---|---|
| 科学程序 | FSD-EY/1FME、OpenMM、既有 mdlearn CVAE；CONFIRMED |
| 科学目标 | 构象探索；CONFIRMED。具体独立评价函数尚未冻结 |
| 资源 | 1× RTX PRO 6000 96GB；当前单 slot/单 worker、非抢占任务边界 |
| 动作 | 继续 MD；执行一次固定配置的模型更新并重新选择；推迟更新后再执行。候选语义待批准 |
| 固定因素 | 相同初始分布、MD 参数、选择算法、CVAE 架构/更新配方、CPU 配额、I/O、版本及预算定义 |
| 输出 | 预算内可用的有效 MD 轨迹；不是单个最优 RMSD，也不是 CVAE loss |
| 目前不可承诺 | 科学收益、足够的独立重复数、正式状态尺度、最优性、可推广至多卡/异构集群 |

“推迟”不是白白等待：在可用 GPU 上继续已就绪 MD，并保留待更新请求。若没有可执行 MD，idle 必须另记。固定触发规则产生请求和调度决定何时服务请求是不同层次；正式研究若允许取消/合并请求，必须明确这是更新政策而不仅是队列排序，不能把旧框架里的固定触发权限悄悄扩大。

## 2. 时间、数据与结果的定义

- \(H>0\)：从共同起点计的端到端观测预算，单位秒。\(t\) 为单调墙钟经过秒数，\(h=H-t\) 为剩余时间。
- \(D_t\)：截至 \(t\) **已发布、可读且通过预定资格检查**的 MD 帧及来源清单；其大小不是独立样本量。
- \(\theta_t\)：实际可用 CVAE 版本；\(L_t\)：候选排名及其模型版本/数据快照；\(\mathcal H_t\)：仅包含过去已观测事件的完整历史。
- \(\mathcal X_\pi(t)\)：政策 \(\pi\) 在 \(t\) 前公布的合格结构集合。不按轨迹中的物理时间标签倒填尚未发布的结果。
- \(\Psi\)：预先冻结、与被比较 CVAE/策略独立的物理评价器。最简候选为固定可解释结构划分的已访问集合大小 \(U_\Psi(\mathcal X)\)，单位“评价单元”；**不等于亚稳态数或全部可达空间百分比**。S2 补充说明当前候选还未合格。

若使用固定校准中心库，分母仅代表该库，需同时报告库外比例；不得将每个库外帧当作独立新科学状态。固定评估器既要防止一帧一状态退化，也要查过粗合并和短暂高能异常导致的虚假覆盖。具体质量过滤/停留要求需领域依据，不在本文指定数值。

沿用现有 H/排空区分：H 后才发布的输出不计主要结果；已接纳任务可自然结束，但排空费用单独报告并保证许可覆盖。若未来想实行硬 GPU 时间上限，需另定准入规则，不能在本文把旧运行语义改成硬截止。公平比较至少同时报告预算内结果和含排空的总资源账，避免利用超时完成数据获益。

## 3. 可审计的成本与目标

单槽互斥下，窗口内占槽时间满足

\[
C^{[0,H]}_{MD}+C^{[0,H]}_{train}+C^{[0,H]}_{infer}+C^{[0,H]}_{other}+C^{[0,H]}_{idle}=H.
\]

各项按互斥时间区间分区，不把嵌套 reporter I/O、进程准备和训练 fit 重复相加。CPU 预处理若实际与 GPU 重叠，不能再把 CPU 秒直接叠入 H；记录资源区间与关键路径即可。GPU 预留小时和设备忙碌比例不同。

主目标草案：

\[
J_H(\pi)=\mathbb E[U_\Psi(\mathcal X_\pi(H))-U_\Psi(\mathcal X_\pi(0))]. \tag{1}
\]

期望针对独立 campaign 的初始条件/MD/训练随机性，不是对同一轨迹帧求独立重复。去掉公共初始覆盖，防止把校准/预训练历史当本次成果。初始模型的建立成本可选择各臂共同计入 H，或作为明确的共同部署前成本，但必须预先统一并单列，不能给某臂免费额外预训练。

辅助指标：覆盖随墙钟轨迹、相同累计 MD 物理时间下的覆盖、有效 ns、准备/更新/选择成本、更新到首次采用延迟、未被采用的更新次数。面积指标 \(H^{-1}\int_0^H U_\Psi(\mathcal X_\pi(t))dt\) 若使用只能事前指定为辅指标，因为它偏好早获益，与终点覆盖并非同一目标。

## 4. 更新价值应是同一剩余时间下的反事实差值

从同一合法分支点历史 \(\mathcal H_t\) 出发，规定两种首个动作并使用同一预定后续政策 \(\pi_0\)：

\[
\Delta_H(\mathcal H_t;\pi_0)=
\mathbb E[U_\Psi(\mathcal X_H^{update\rightarrow\pi_0})\mid\mathcal H_t]
-
\mathbb E[U_\Psi(\mathcal X_H^{continue\rightarrow\pi_0})\mid\mathcal H_t]. \tag{2}
\]

两项从同一 t 起、到同一 H 止。更新臂包含实际数据准备、训练、权重发布、推理、排名发布和下游 MD 的耗时；继续臂把相应时间用于允许的 MD/旧模型选择。因而机会成本已经进入式(2)，**不能再任意减去“训练秒数”当覆盖损失**。

该定义不是可直接在线取得的数值：一次真实执行只能观察一条后续路径，另一条是反事实。受控分支可以估计条件性差异，但其成本与常规执行不同，且每个分支结果需独立随机重复。共用初始快照/模型可以配对，不能要求两政策运行后仍有相同候选池——候选池的变化正是总政策效果的一部分。

同候选池冻结/更新比较是机制实验；完整闭环比较是总政策实验；不同时间状态间的关联不是同状态动作效应。共享随机数只用于合法、明确的配对，不保证分歧后的非线性轨迹逐点可比。

## 5. 候选变化如何进入证据链

记固定候选池 \(P\) 上的前 k 个选项为 \(K(\theta,P)\)。一种纯诊断为

\[
d_K=1-\frac{|K(\theta_{old},P)\cap K(\theta_{new},P)|}{|K(\theta_{old},P)\cup K(\theta_{new},P)|}. \tag{3}
\]

它衡量选择差异，不能当作 \(\Delta_H\) 的估计；候选 ID 不同也可能物理等价，离群值也可能无科学意义。应额外检查固定物理距离、合法输入与下游覆盖。

特别重要的在线可知性：\(d_K\) 通常在新模型训练和推理后才能算出。若用它决定“是否值得开始这次训练”，就使用了未来信息。它可作事后分析、下一次更新的历史特征或研究上界；若设计廉价探测器，探测成本、偏差与可用时点必须入账，且需要新批准。本文不引入该预测器。

机制链应完整记录：新结果发布→训练快照→模型发布→排名发布→MD 实际采用→该 MD 输出在 H 前可用。版本关系证明采用，不证明该条训练数据的单独因果贡献。

## 6. 有限时域的必要条件与非新颖性

令 \(\tau_u\) 为从开始更新到新排名可用的实际关键路径秒数；\(\tau_m^{min}\) 为从新起点到**最早合格且可计分的 MD 输出可用**的可信下界。在更新本身不产生可计 MD 成果、不能中途采用权重、无额外并行槽、只评价本窗口的前提下：

\[
h < \tau_u+\tau_m^{min}\quad\Rightarrow\quad
\text{这次更新无法通过新起点在 H 前产生可计的下游收益}. \tag{4}
\]

这是因果路径的必要条件，**不是新的调度定理，也不是充分收益条件**。若任务能流式发布合格帧，\(\tau_m^{min}\) 不是完整 MD 任务时长；若允许跨窗口复用模型，结论范围也改变。实际运行时间未知时，估计值不是保证；可用开发数据给保守分位成本，但误判率和耗费须检查，不能冒称硬界。

Ekya §3.2/§4 已优化有限窗口内收益；ORRIC §V 权重随剩余轮次降低；Hay §2 明确时间可作为元决策状态。因此“加上 H−t”没有独立理论创新。

## 7. 形式化决策框架及其局限

可用历史态的有限时域半马尔可夫描述：动作 \(a\) 有随机耗时 \(\tau_a\)，改变模型、数据与已访问集合。若记完整可充分描述未来的状态为 s，未来新增覆盖的最优值形式为

\[
V(s,h)=\max_{a\in\mathcal A(s)}\mathbb E[r_\Psi(s,a,\tau_a;h)+V(s',h-\tau_a)\,\mathbf1\{\tau_a<h\}], \tag{5}
\]

其中 \(r_\Psi\) 只累计 h 内发布的新评价单元；记录已访问集合是避免重复计分的必要部分。训练动作的即时科学奖励为零，但可改变未来选择。约定 h≤0 时 V(s,h)=0，终止动作值为零；这样式(5)不会在负剩余时间调用未定义的值。本式用来解释依赖关系，不是已求解的策略、复杂度结果或性能保证。以有限几个年龄/队列特征替代完整历史后，Markov 性通常未验证，不能直接宣称得到正确 MDP。

相比固定外部数据流，MD 动作同时改变当前科学产出与以后训练数据的分布。这个结构在 Colmena、AL-Queue、REAP 已有；P1 候选贡献只能是具体约束下未被既有比较回答的量化问题。

## 8. 最小比较阶梯（全部 PROPOSED，未授权执行）

1. **F0 冻结模型**：不更新，但用同一已批准选择规则对新数据推理；不能把冻结等同于永远沿用旧队列。
2. **固定更新族**：经独立开发数据调优的若干更新间隔，训练配方、MD 片段、候选规则固定。保留上游机制的忠实参考，但不得把换后的 native-free 版本叫原论文逐项复现。
3. **固定更新+截止保护**：同一固定策略，只在更新和最早可计下游结果不能及时完成时推迟/跳过；这是必须击败的简单强基线，不应仅包装成主创新。
4. **状态附加规则（条件候选）**：只有受控证据显示反馈状态在成本/剩余时域之外还有增量解释力，才考虑一个可观测、便宜且可解释的规则。复杂价值预测不在当前必做范围。
5. **科学诊断对照**：连续 MD 或随机/低占有率 restart 是否必要由研究者决定，用来检查 gains 是否只是 restart 本身；不能悄悄变更已确认科学算法。

下一份规格必须冻结预算、窗口截断、样本单位、初始成本、train recipe、参数搜索预算、独立校准与确认数据、最小有意义差异和失败处理。没有这些条件，不应把目前的形式化草案当可直接启动 S3 的指令。
